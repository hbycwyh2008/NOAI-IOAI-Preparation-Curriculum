# Student Mastery Dashboard

Copy this dashboard into your own course repository at the beginning of the course. Update it after every assigned Session and review it with your teacher at checkpoints.

This dashboard is not a completion checklist. A box is supported only when it links to evidence that you can explain and reconstruct.

## Mastery Scale

| Level | Meaning | Acceptable evidence |
|---:|---|---|
| 0 | Not attempted or no usable evidence | none |
| 1 | Followed an example with substantial support | annotated attempt and identified confusion |
| 2 | Reconstructed with notes or prompts | working rebuild plus explanation of key steps |
| 3 | Completed independently and explained decisions | reproducible artifact, tests or checks, and oral/written explanation |
| 4 | Transferred the skill to a new task under constraints | independent transfer, comparison, error analysis, and limitation statement |

Do not raise a score because code ran once. Link the evidence and record what you can now do without help.

## Weekly Review

Complete this section once per week.

### 1. Evidence That Changed My Mind

What result, error, graph, test, or discussion forced you to revise an earlier belief?

### 2. One Skill I Can Now Reconstruct

Name the skill and describe what you can rebuild without copying.

### 3. One Error Pattern That Is Repeating

Describe the pattern precisely. Examples include confusing `X` and `y`, choosing a model from keywords, leaking validation information, changing multiple variables at once, or reporting a score without error analysis.

### 4. One Controlled Next Step

Write one action that is small enough to test and clear enough to evaluate.

### 5. Retrieval Check

Choose one previous skill and rebuild or explain it without opening the original solution. Link the new evidence.

## Promotion Rules

A student is ready to advance when all of the following are true:

- the required evidence exists and is accessible;
- the student can explain the purpose of the work, not only the syntax;
- the student can reconstruct the central pattern with limited or no prompting;
- the student can identify at least one failure mode or limitation;
- the next Phase does not depend on an unresolved prerequisite.

Use these response rules:

- **Level 0–1:** pause advancement for the affected prerequisite and complete a guided rebuild;
- **Level 2:** continue with targeted retrieval and one independent transfer task;
- **Level 3:** advance while scheduling spaced retrieval;
- **Level 4:** use the student as an explainer only after independent evidence is verified.
