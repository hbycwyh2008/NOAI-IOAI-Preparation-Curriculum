# Detailed Lesson Sequence

The recommended pathway contains **75 scheduled sessions**.

## Phase 0 — Orientation and Evidence

1. Competition expectations, official rules, and course map
2. GitHub, Bohrium, Jupyter, evidence, and responsible artificial-intelligence use

## Phase 1 — CS50P Python

3. Functions, variables, input, and output
4. Types, conversion, and debugging
5. Conditionals and Boolean reasoning
6. Loops
7. Strings, lists, dictionaries, and tuples
8. Function decomposition and tracing
9. Libraries, modules, imports, and documentation
10. Exceptions and defensive input handling
11. Files, CSV records, and data-oriented scripts
12. Unit tests, classes, and Python mastery checkpoint

## Phase 2 — NumPy, Pandas, and Visualisation

13. NumPy arrays, shapes, indexing, and dtypes
14. Vectorisation and broadcasting
15. Pandas DataFrames, selection, and filtering
16. Grouping, merging, reshaping, and summary statistics
17. Missing values, duplicates, types, and basic data checks
18. Matplotlib and a mini exploratory-data-analysis project

## Phase 3 — Bohrium Machine-Learning Foundations

19. Course map and evidence expectations
20. Definition of artificial intelligence
21. Artificial-intelligence history, schools, and Turing Test
22. Connectionism and machine learning
23. Object-oriented programming and machine-learning libraries
24. Machine-learning workflow and training paradigms
25. Classification and logistic regression
26. Optimisation and gradient descent
27. Neural networks and backpropagation
28. K-nearest neighbours and Bayes reasoning
29. Support vector machines and margins
30. Entropy, decision trees, multiclass learning, and ensembles
31. Unsupervised learning and reinforcement learning
32. Deep neural networks and bridge to Round 2

## Phase 4 — Kaggle Machine-Learning Refresh

33. Pandas refresh: X, y, types, and missingness
34. Data-visualisation refresh: diagnostic questions and plots
35. Intro to Machine Learning: split, baseline, metric, prediction
36. Intermediate Machine Learning: preprocessing, pipelines, cross-validation, leakage
37. Mini Kaggle workflow: controlled improvement, submission validation, postmortem

## Phase 5 — Andrew Ng ML and Model Labs

38. Machine-learning workflow and model-recognition routine
39. Linear regression: vectors, dot products, slope, and residuals
40. Multiple regression, scaling, cost surfaces, and gradient descent
41. Logistic regression, sigmoid, probability, and decision boundaries
42. Thresholds, confusion matrix, and classification errors
43. Regularisation, generalisation, bias, and variance
44. Neural-network introduction in the Machine Learning Specialization
45. Decision trees and split criteria
46. Random forests and bagging
47. Boosting and model correction
48. K-nearest neighbours and distance reasoning
49. Support vector machines and margin intuition
50. K-means clustering
51. PCA and dimensionality-reduction intuition
52. Anomaly detection
53. Recommender systems and vector similarity
54. Reinforcement-learning introduction
55. Classical-machine-learning capstone and mixed model-recognition assessment

## Phase 6 — Andrew Ng DL and PyTorch

56. Deep-learning map, tensor shapes, and baseline discipline
57. Forward propagation and PyTorch tensors/`nn.Module`
58. Backpropagation, autograd, and complete training loop
59. Initialisation, optimisers, BatchNorm, Dropout, and regularisation
60. Convolutional-neural-network concepts and shape reasoning
61. PyTorch image-classification task
62. Transfer learning and augmentation
63. Recurrent neural networks and long short-term memory networks
64. PyTorch text or time-series classification
65. Attention and Transformer intuition
66. Audio or multimodal task
67. Deep-learning capstone: baseline versus deep model

## Phase 7 — Model Comparison, EDA, and Evaluation

68. Model-family comparison: strengths, assumptions, limitations, cost, and interpretability
69. EDA, data quality, distribution shift, imbalance, groups/time, and leakage
70. Feature engineering, reproducible pipelines, selection, and ablation
71. Validation design, metrics, thresholds, learning curves, calibration, and error analysis

## Phase 8 — Tuning, Ensembling, and Competition

72. Diagnosis-first tuning and controlled search
73. Model ensembling, diversity, and out-of-fold stacking
74. Full competition simulation
75. Postmortem and readiness conference

## Timing

Ordinary sessions are 75 minutes. Sessions 19–32 use the named 70-minute Bohrium format. Session 74 uses the target competition duration.
