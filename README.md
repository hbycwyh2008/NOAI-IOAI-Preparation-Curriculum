# NOAI / IOAI Preparation Curriculum

A **competition-first**, **evidence-based**, and **mastery-focused** curriculum for preparing secondary-school students for the NOAI China selection pathway and later IOAI-style open-ended artificial-intelligence challenges.

Students do not receive credit merely for watching videos or running code once. They must **recognise, explain, calculate or trace, rebuild or debug, modify or apply, and compete under constraints**.

## Curriculum Structure

This repository is a **curriculum bank**, not a requirement that every cohort complete every lesson file.

| Layer | Count | Purpose |
|---|---:|---|
| Core scheduled pathway | 67 sessions | compressed pathway from orientation through Round 1, Round 2, projects, mocks, and readiness |
| Competition sprint | 8 sessions | task recognition, data engineering, classical/deep-learning tuning, PyTorch tuning, and full simulation |
| Recommended full competition pathway | 75 sessions | 67 core sessions plus the eight-session competition sprint |
| Mainline mission bank | 155 lessons | deeper practice, alternatives, reteaching, and domain extension across Modules 00–26 and 28 |
| Optional Bohrium resource hub | 16 lessons | full-video missions and the fourteen-session 70-minute sequence for 北京市十一学校《中学机器学习十五讲》 |

## Classroom Flow

The ordinary after-school club class is **75 minutes**. Every ordinary class follows the same seven-step cycle:

**Skill Warm-Up → Talk Robin 1 → Entry Check → Core Pattern → Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence**

**WE LEARN. PRACTICE. REBUILD. SHARE.**

The goal is not just to finish the task. The goal is to **rebuild and explain it independently**.

The fourteen-session split for 北京市十一学校《中学机器学习十五讲》 is a named **70-minute exception**. Long mocks and reproductions use competition-realistic durations.

See [75-Minute After-School Club Implementation](09_Teacher_Planning/75min_After_School_Club_Implementation.md) and [Classroom Flow](02_Class_Missions/shared/classroom-flow.md).

## Competition Pathway

```text
Setup and evidence system
→ Python foundations
→ artificial-intelligence and machine-learning foundations
→ Round 1 paper-based mastery
→ data analysis and feature engineering
→ scikit-learn and PyTorch workflows
→ computer vision / natural-language processing / audio / large-language-model tasks
→ Round 2 open-ended projects
→ past-paper reproduction
→ timed mock contests
→ competition sprint: task recognition → data engineering → tuning → full simulation
```

## Evidence Model

Every substantial mission requires:

- focused concept notes;
- a completed practice task;
- an **independent rebuild**;
- an error or debug log;
- a revision record;
- an artificial-intelligence-use note when assistance was used;
- meaningful Git commit history;
- fresh-runtime evidence for competition code when applicable.
