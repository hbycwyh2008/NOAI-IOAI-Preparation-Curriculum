# NOAI / IOAI Preparation Curriculum

A mastery-focused curriculum for secondary-school students preparing for NOAI China and later IOAI-style open-ended artificial-intelligence tasks.

## Canonical Learning Path

```text
CS50P Python
→ NumPy, Pandas, and visualisation
→ 北京市十一学校《中学机器学习十五讲》 on Bohrium
→ Kaggle machine-learning workflow refresh
→ Andrew Ng Machine Learning Specialization
   + StatQuest
   + 3Blue1Brown
   + model-recognition drills
   + typical model tasks
→ Andrew Ng Deep Learning Specialization
   + PyTorch
   + image, text, audio, and multimodal tasks
→ model comparison
→ EDA and data quality
→ feature engineering
→ model evaluation and error analysis
→ tuning
→ model ensembling
→ full competition simulation
```

## Curriculum Layers

| Layer | Count | Purpose |
|---|---:|---|
| Canonical scheduled pathway | 75 sessions | the actual recommended learning order |
| Mainline lesson bank | 155 lessons | deeper practice, remediation, alternatives, and domain extension |

| Total public lesson/resource files | 171 | selectable material; not an instruction to schedule everything |

## Classroom Flow

Ordinary classes use:

**Skill Warm-Up → Talk Robin 1 → Entry Check → Core Pattern → Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence**

The fourteen Bohrium foundation lessons use a named 70-minute format. Long mocks use competition-realistic durations.

## Evidence Standard

Watching a video or running supplied code is not mastery. Students must recognise, explain, trace or calculate, rebuild or debug, apply to a new task, analyse errors, and produce reproducible evidence.
