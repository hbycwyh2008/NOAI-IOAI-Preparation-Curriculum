# Starter Notebooks

This folder contains public student-facing starter-notebook guidance for Round 2 C/D coding-heavy work.

Do not place complete solution notebooks, hidden labels, or private test labels in this folder.

## Coverage

- [Round 2 Starter Notebook Coverage Map](Round2_Starter_Notebook_Coverage.md)

## Required Notebook Evidence

Every Round 2 starter notebook should support:

1. environment check;
2. data audit;
3. split strategy;
4. baseline model;
5. validation metric;
6. controlled experiment;
7. error analysis;
8. submission validation;
9. fresh-run record;
10. AI-use note when applicable.

## Teacher Boundary

Teacher solution notebooks and hidden labels belong in the private teacher-key repo.
