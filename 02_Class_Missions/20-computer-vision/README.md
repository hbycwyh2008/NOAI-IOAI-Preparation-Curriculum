# 20 — Computer Vision

This module prepares students for Round 2 image tasks and IOAI-style visual reasoning. It should not stop after one OpenCV lesson and one CNN lesson.

## Lessons

- [Lesson 01 — OpenCV structural baselines and preprocessing](lesson-01.md)
- [Lesson 02 — CNN baseline, augmentation, and transfer learning](lesson-02.md)
- [Lesson 03 — Detection/segmentation workflow and error analysis](lesson-03.md)
- [Lesson 04 — Image datasets, transforms, and train/validation leakage](lesson-04-image-datasets-and-transforms.md)
- [Lesson 05 — Transfer learning and fine-tuning under time limits](lesson-05-transfer-learning-finetuning.md)
- [Lesson 06 — Error analysis, class imbalance, and submission strategy](lesson-06-image-error-analysis-submission.md)

## Minimum Evidence

Students should submit a classical baseline, a CNN or transfer-learning baseline, an augmentation decision memo, and an error-analysis table.
