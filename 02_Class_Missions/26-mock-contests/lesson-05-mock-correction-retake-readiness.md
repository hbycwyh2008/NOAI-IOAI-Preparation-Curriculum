# Lesson 05 — Mock Correction, Retake Plan, and Readiness Decision

**Duration:** 75 minutes, or longer if attached to a full mock correction block.

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review mock score and time-use notes. |
| 8–15 min | Talk Robin 1 | Explain one high-value error to a partner. |
| 15–22 min | Entry Check | Categorise errors: knowledge, calculation, code, strategy, or time. |
| 22–35 min | Core Pattern | Teacher models error pattern → correction → retest → readiness decision. |
| 35–53 min | Guided Practice | Correct representative errors. |
| 53–67 min | Independent Rebuild | Write retake plan and readiness checklist. |
| 67–75 min | Talk Robin 2 + Evidence | Submit readiness decision. |

## Core Pattern

```text
Mock result → error categories → root cause → targeted correction → retest plan → readiness decision
```

## Evidence

Submit score record, error categories, corrected work, retake plan, and readiness decision.
