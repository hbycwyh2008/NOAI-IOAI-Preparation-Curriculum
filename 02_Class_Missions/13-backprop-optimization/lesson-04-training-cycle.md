# Lesson 04 — Forward, Loss, Backward, and Optimiser-Step Training Cycle

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect a minimal training-cycle diagram. |
| 8–15 min | Talk Robin 1 | Discuss what happens before and after loss. |
| 15–22 min | Entry Check | Order training-cycle steps. |
| 22–35 min | Core Pattern | Teacher explains forward → loss → backward → update. |
| 35–53 min | Guided Practice | Annotate a training loop. |
| 53–67 min | Independent Rebuild | Rebuild the training cycle in words or pseudocode. |
| 67–70 min | Talk Robin 2 + Evidence | Submit cycle explanation. |

## Core Pattern

```text
Batch → Forward pass → Loss → Backward pass → Optimiser step → Validation check
```

## Required Evidence

1. Ordered training steps.
2. Annotated training-loop explanation.
3. Independent cycle rebuild.
