# Lesson 05 — Local Optimum, Global Optimum, Learning Rate, and Convergence

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare three loss curves. |
| 8–15 min | Talk Robin 1 | Discuss which curve shows a training problem. |
| 15–22 min | Entry Check | Identify too-high, too-low, and reasonable learning rate. |
| 22–35 min | Core Pattern | Teacher explains learning rate, convergence, local/global optimum. |
| 35–53 min | Guided Practice | Diagnose training curves. |
| 53–67 min | Independent Rebuild | Write a remedy plan for a new curve. |
| 67–70 min | Talk Robin 2 + Evidence | Submit curve diagnosis. |

## Core Pattern

```text
Loss curve → Training behaviour → Cause hypothesis → Learning-rate/optimiser remedy → Evidence
```

## Required Evidence

1. Curve diagnosis table.
2. Learning-rate misconception correction.
3. One remedy plan.
