# Lesson 06 — Round 1 Backpropagation and Optimisation Explanation Practice

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read a Round 1-style explanation prompt. |
| 8–15 min | Talk Robin 1 | Discuss what a scoring answer must include. |
| 15–22 min | Entry Check | Define gradient descent and backpropagation briefly. |
| 22–35 min | Core Pattern | Teacher models mechanism-based explanation. |
| 35–53 min | Guided Practice | Improve weak answers. |
| 53–67 min | Independent Rebuild | Write one original scoring answer. |
| 67–70 min | Talk Robin 2 + Evidence | Submit answer and self-rubric. |

## Core Pattern

```text
Training goal → Loss → Gradient → Backpropagation → Parameter update → Better prediction
```

## Required Evidence

1. Definitions of gradient descent and backpropagation.
2. One improved weak answer.
3. One original scoring answer with rubric notes.
