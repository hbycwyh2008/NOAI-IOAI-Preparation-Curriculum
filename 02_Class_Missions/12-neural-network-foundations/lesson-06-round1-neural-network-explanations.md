# Lesson 06 — Neural-Network Misconceptions and Round 1 Short Answers

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read common neural-network misconceptions. |
| 8–15 min | Talk Robin 1 | Explain which misconception is most tempting. |
| 15–22 min | Entry Check | Correct two false statements. |
| 22–35 min | Core Pattern | Teacher models a precise Round 1 short answer. |
| 35–53 min | Guided Practice | Rewrite weak answers into scoring answers. |
| 53–67 min | Independent Rebuild | Write one original short answer and rubric. |
| 67–70 min | Talk Robin 2 + Evidence | Submit short answer and self-check. |

## Core Pattern

```text
Term → Mechanism → Example → Common misconception → Correct explanation
```

## Required Evidence

1. Two corrected misconceptions.
2. One improved short answer.
3. One original neural-network Round 1 item.
