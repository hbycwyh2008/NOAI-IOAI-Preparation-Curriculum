# Lesson 03 — Activation Functions, Decision Functions, and Loss Functions

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare activation, decision, and loss examples. |
| 8–15 min | Talk Robin 1 | Discuss what each function does. |
| 15–22 min | Entry Check | Match function type to purpose. |
| 22–35 min | Core Pattern | Teacher explains representation → decision → loss. |
| 35–53 min | Guided Practice | Classify functions and choose correct loss for tasks. |
| 53–67 min | Independent Rebuild | Build a new task-function mapping. |
| 67–70 min | Talk Robin 2 + Evidence | Submit mapping and explanation. |

## Core Pattern

```text
Input signal → Activation → Network output → Decision function → Loss → Training signal
```

## Required Evidence

1. Function-purpose table.
2. Correct loss choice for regression and classification.
3. One short-answer explanation suitable for Round 1.
