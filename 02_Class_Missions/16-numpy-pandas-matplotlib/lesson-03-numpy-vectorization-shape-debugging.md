# Lesson 03 — NumPy Vectorisation, Masks, and Shape Debugging

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect array shapes and masks. |
| 8–15 min | Talk Robin 1 | Explain why vectorisation changes code structure. |
| 15–22 min | Entry Check | Predict shape after indexing or masking. |
| 22–35 min | Core Pattern | Teacher models array → shape → operation → resulting shape. |
| 35–53 min | Guided Practice | Complete supported vectorised operations. |
| 53–67 min | Independent Rebuild | Rebuild a loop as a vectorised operation. |
| 67–75 min | Talk Robin 2 + Evidence | Submit shape ledger and explanation. |

## Core Pattern

```text
Array shape → operation axis/mask → broadcast rule → result shape → sanity check
```

## Evidence

Submit shape ledger, one vectorised rewrite, and one debugging note.
