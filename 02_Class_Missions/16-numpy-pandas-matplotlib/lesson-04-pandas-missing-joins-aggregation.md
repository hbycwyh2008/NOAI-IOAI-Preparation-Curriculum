# Lesson 04 — Pandas Missing Values, Joins, Grouping, and Aggregation

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect a messy dataframe. |
| 8–15 min | Talk Robin 1 | Discuss missing values and grouping purpose. |
| 15–22 min | Entry Check | Identify missing-value, join, and aggregation operations. |
| 22–35 min | Core Pattern | Teacher models inspect → clean → join/group → aggregate → verify. |
| 35–53 min | Guided Practice | Complete supported Pandas audit tasks. |
| 53–67 min | Independent Rebuild | Design a groupby summary for a new question. |
| 67–75 min | Talk Robin 2 + Evidence | Submit audit table and explanation. |

## Core Pattern

```text
Question → relevant columns → missing check → join/group choice → aggregation → verification
```

## Evidence

Submit a Pandas audit, groupby summary, and one cleaning decision memo.
