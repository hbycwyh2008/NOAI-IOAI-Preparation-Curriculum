# Lesson 06 — Round 2 Data Audit Notebook and Reproducibility Check

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read a minimal data-audit notebook structure. |
| 8–15 min | Talk Robin 1 | Discuss what makes a notebook reproducible. |
| 15–22 min | Entry Check | Identify required audit sections. |
| 22–35 min | Core Pattern | Teacher models load → inspect → validate → visualise → record decision. |
| 35–53 min | Guided Practice | Complete supported audit notebook cells. |
| 53–67 min | Independent Rebuild | Rebuild the audit on a new dataset sample. |
| 67–75 min | Talk Robin 2 + Evidence | Submit fresh-run evidence. |

## Core Pattern

```text
Load data → schema audit → missing/type checks → diagnostic plots → decision memo → fresh run
```

## Evidence

Submit audit notebook, decision memo, and fresh-runtime screenshot or log.
