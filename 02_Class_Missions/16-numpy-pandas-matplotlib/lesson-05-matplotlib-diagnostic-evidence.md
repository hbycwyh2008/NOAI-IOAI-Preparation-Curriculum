# Lesson 05 — Matplotlib Diagnostic Plots and Visual Evidence

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare unclear and useful plots. |
| 8–15 min | Talk Robin 1 | Discuss what evidence a plot should show. |
| 15–22 min | Entry Check | Match plot type to diagnostic purpose. |
| 22–35 min | Core Pattern | Teacher models question → plot choice → labels → interpretation. |
| 35–53 min | Guided Practice | Create supported diagnostic figures. |
| 53–67 min | Independent Rebuild | Make one plot for a new question. |
| 67–75 min | Talk Robin 2 + Evidence | Submit figure and interpretation. |

## Core Pattern

```text
Diagnostic question → plot type → axes/labels → pattern observed → decision evidence
```

## Evidence

Submit one labelled plot, interpretation, and decision note.
