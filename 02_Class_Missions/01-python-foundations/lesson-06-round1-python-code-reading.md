# Lesson 06 — Round 1 Python Code-Reading Mixed Practice

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review assigned CS50P timestamp map and read a short Round 1-style code fragment. |

| 15–22 min | Entry Check | Complete two short traces. |

## 2. Talk Robin 1

Prompt: what is the final value and which line is most likely to cause a wrong answer?

## 3. Entry Check

1. Trace a variable through three assignments.
2. Predict loop output for a boundary case.
3. Explain one distractor.

## 4. Core Pattern

```text
Read input/state → trace each line → update variables → predict output → check distractors
```

## 5. Guided Practice

Students complete 5 short items: function call, type conversion, loop count, list indexing, dictionary update.

## 6. Independent Rebuild

Write one Round 1-style Python code-reading question with one correct answer and two plausible distractors.

## 7. Talk Robin 2 + Evidence

Submit CS50P timestamp review notes, trace work, final answers, original question, and distractor explanation.
