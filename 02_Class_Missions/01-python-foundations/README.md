This module builds Round 1 A/B Python fluency. Two lessons are not enough for students who must read, trace, debug, and write small programs under paper-test conditions.

## Minimum Evidence

Students should submit a trace table, one multi-function program, one debugging record, one documentation-use note, and one Round 1-style code-reading explanation.
