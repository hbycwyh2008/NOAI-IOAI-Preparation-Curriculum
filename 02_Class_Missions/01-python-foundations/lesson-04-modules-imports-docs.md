## 2. Talk Robin 1

Prompt: what could the program not do before the import?

## 3. Entry Check

1. Which module is useful for square roots?
2. Which module is useful for random selection?
3. What should you check before using an unfamiliar third-party package?

## 4. Core Pattern

```text
Need → choose module → read documentation → identify function → check arguments → test minimal example
```

## 5. Guided Practice

Students complete a documentation card: module, function, purpose, required arguments, return value, minimal example.

## 6. Independent Rebuild

Create a small utility that uses one standard module and includes a one-paragraph documentation-use note.

## 7. Talk Robin 2 + Evidence

Submit the CS50P segment notes, documentation card, utility code, and one sentence explaining why blind copy-paste is risky.
