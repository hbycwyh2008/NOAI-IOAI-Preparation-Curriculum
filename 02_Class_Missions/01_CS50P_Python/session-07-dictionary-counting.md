# Lesson 05 — Dictionary Counting and Frequency-Table Patterns

**Duration:** 75 minutes

## Resource Delivery

**Pre-class required viewing:** Complete the assigned segments from **Harvard CS50’s Introduction to Programming with Python** before class. In class, use the warm-up to retrieve the dictionary-update pattern rather than replaying the full assigned viewing.

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Retrieve the dictionary pattern from pre-class viewing and trace one frequency update. |
| 8–15 min | Talk Robin 1 | Explain why a dictionary fits the task. |
| 15–22 min | Entry Check | Update a dictionary by hand. |
| 22–35 min | Core Pattern | Teacher models check key → initialise/update → interpret counts. |
| 35–53 min | Guided Practice | Build a frequency table from a list or string. |
| 53–67 min | Independent Rebuild | Rebuild counting for a new dataset. |
| 67–75 min | Talk Robin 2 + Evidence | Explain one common key error and submit the evidence set. |
