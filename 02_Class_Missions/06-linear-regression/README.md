# 06 — Linear Regression

This module prepares students to reason about regression, residuals, cost, fitting, scaling, and gradient descent in both paper-test and simple coding contexts.

## Lessons

- [Lesson 01 — Model, prediction, residual, and cost](lesson-01.md)
- [Lesson 02 — Gradient descent, feature scaling, and multiple regression](lesson-02.md)
- [Lesson 03 — Linear regression paper calculations and interpretation](lesson-03-paper-calculations-interpretation.md)
- [Lesson 04 — Regression baseline, error analysis, and Round 2 bridge](lesson-04-regression-baseline-error-analysis.md)

## Minimum Evidence

Students should submit a residual/cost calculation, one gradient-descent explanation, one feature-scaling explanation, and one baseline-vs-improved regression comparison.
