# Lesson 04 — Threshold Choice and Trade-off Reasoning

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect a classifier with probability scores and two possible thresholds. |
| 8–15 min | Talk Robin 1 | Discuss what changes when the threshold changes. |
| 15–22 min | Entry Check | Compute TP, FP, TN, FN for one threshold. |
| 22–35 min | Core Pattern | Teacher explains threshold → confusion matrix → metric trade-off → decision. |
| 35–53 min | Guided Practice | Compare two thresholds using precision, recall, and F1. |
| 53–67 min | Independent Rebuild | Choose a threshold for a new scenario and defend it. |
| 67–70 min | Talk Robin 2 + Evidence | Submit metric table and decision memo. |

## Learning Target

Students can explain why changing a classification threshold changes precision, recall, and F1, and can choose a threshold based on task risk.

## Core Pattern

```text
Probability score → Threshold → Predicted class → Confusion matrix → Metric trade-off → Decision
```

## Required Evidence

1. Threshold comparison table.
2. Precision/recall/F1 calculation.
3. One threshold decision memo.
4. One misconception corrected: "higher accuracy is always better."
