# 07 — Model Comparison, EDA, and Evaluation

**Scheduled sessions:** 71–74

## Start Here

[**Open the Phase 7 Session Launcher**](SESSION_LAUNCHER.md)

The launcher selects the exact comparison, EDA, feature-engineering, validation, and error-analysis lessons. Do not browse the lesson library manually.

## Purpose

Systematise model choice, data quality, feature engineering, validation, metrics, thresholds, learning curves, and error analysis after students have experienced multiple model families.

## Required Artifact

Students produce a model-selection handbook containing model family, suitable data/output, assumptions, preprocessing, mathematical mechanism, strengths, limitations, overfitting risks, training/inference cost, metrics, and typical failure evidence.

## Gate

Students defend a validation design and model choice from evidence, not familiarity, preference, or leaderboard score.
