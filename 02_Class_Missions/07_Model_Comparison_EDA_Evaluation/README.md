# 07 — Model Comparison, EDA, and Evaluation

**Scheduled sessions:** 68–71

Basic data checks and metrics appear inside earlier tasks. This phase systematises them after students have experienced multiple model families.

## Sequence

1. **Model comparison** — linear, distance-based, tree, ensemble, kernel, and neural models; assumptions, strengths, limits, interpretability, data demand, and compute.
2. **EDA and data quality** — schema, identifiers, missingness, duplicates, outliers, imbalance, target distribution, groups/time, shift, and leakage.
3. **Feature engineering** — reproducible pipelines, encoding, scaling, domain features, feature selection, and ablation.
4. **Model evaluation and error analysis** — split design, cross-validation, metrics, thresholds, calibration, learning curves, slices, and failure cases.

## Lesson Library Modules

`08-statistics-probability-distance`, `09-model-evaluation`, `10-generalization-regularization`, `11-trees-and-ensembles`, `17-data-cleaning-feature-engineering`, and `18-sklearn-workflow`.

## Required Artifact

Students produce a model-selection handbook containing model family, suitable data and output, assumptions, preprocessing, strengths, limitations, overfitting risks, training/inference cost, metrics, and typical failure evidence.

## Gate

Students can defend a validation design and model choice from evidence, not preference or leaderboard score.
