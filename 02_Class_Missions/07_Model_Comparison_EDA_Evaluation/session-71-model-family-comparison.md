# Session 71 — Model-Family Comparison

**Class duration:** 75 minutes

## Required Mastery

Students must be able to compare:

- linear and logistic models;
- distance-based models;
- trees and ensembles;
- margin/kernel models;
- clustering and dimensionality reduction;
- neural networks and deep models.

For each family, students identify:

1. suitable input and output types;
2. core mathematical or decision mechanism;
3. preprocessing needs;
4. assumptions and inductive bias;
5. interpretability;
6. data demand;
7. training and inference cost;
8. typical overfitting behaviour;
9. characteristic failure modes;
10. one appropriate baseline or alternative.

## Core Pattern

```text
task and data structure
→ baseline
→ model-family assumptions
→ validation evidence
→ error pattern
→ cost and operational constraints
→ justified choice
```

## 75-Minute Learning Cycle

| Time | Block | Required action |
|---:|---|---|
| 0–8 | Skill Warm-Up | match six tasks to plausible baselines and model families |
| 8–15 | Talk Robin 1 | defend one model and reject one inappropriate model |
| 15–22 | Entry Check | identify the mechanism and preprocessing need of three families |
| 22–35 | Core Pattern | compare under one task, split, and metric |
| 35–53 | Guided Practice | complete a comparison matrix for one tabular task |
| 53–67 | Independent Rebuild | select models for a new image/text/tabular or clustering task |
| 67–75 | Talk Robin 2 + Evidence | defend the final choice and its failure boundary |

## Required Evidence

- model-family comparison matrix;
- one task-recognition record;
- baseline and contrasting-model choice;
- validation/cost table;
- error-pattern comparison;
- rejected-model explanation;
- model-selection memo.

## Gate

The student selects models from evidence and task structure rather than familiarity, prestige, or leaderboard score.
