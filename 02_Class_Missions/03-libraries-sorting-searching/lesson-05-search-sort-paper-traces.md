# Lesson 05 — Search/Sort Paper Traces and Documentation-Assisted Coding

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Trace linear search, binary search, and one sorting pass. |
| 8–15 min | Talk Robin 1 | Discuss why sorted input matters for binary search. |
| 15–22 min | Entry Check | Complete two trace questions. |
| 22–35 min | Core Pattern | Teacher models state table tracing. |
| 35–53 min | Guided Practice | Solve a mixed search/sort paper set. |
| 53–67 min | Independent Rebuild | Write one original trace question. |
| 67–75 min | Talk Robin 2 + Evidence | Explain answer and distractor. |

## Core Pattern

```text
Initial list → current index/range → comparison → update state → final found/order result
```

## Evidence

Submit trace tables, answers, one original question, and one explanation of a common misconception.
