# Full Bohrium Video Classroom Flow

This template is used when a lesson is built around a complete Bohrium video rather than a short clip.

The video is not treated as passive homework. Students watch the full assigned video, then move through the same seven-step after-school club cycle so that watching becomes explanation, practice, rebuild, and evidence.

## Official-Aligned Bohrium Resources

| Code | Resource | Best use in this curriculum |
|---|---|---|
| BML15 | 北京市十一学校《中学机器学习十五讲》 | Round 1 A/B: Python-related reasoning, AI foundations, core machine-learning concepts, paper-test preparation |
| LHY-ML | 台湾大学李宏毅《机器学习》内容精选版 | Round 2 C/D: deeper machine-learning and deep-learning concepts before or after sklearn/PyTorch practice |

## Required 7-Step Flow

| Step | Block | What happens |
|---:|---|---|
| 1 | **Skill Warm-Up** | Watch the full assigned Bohrium video and complete guided notes. |
| 2 | **Talk Robin 1** | Pair discussion: what the teacher explained, what was understood, and what is still confusing. |
| 3 | **Entry Check** | Answer short concept, code-reading, calculation, or scenario questions based on the video. |
| 4 | **Core Pattern** | The classroom teacher extracts one reusable method, reasoning structure, or modelling pattern from the video. |
| 5 | **Guided Practice** | Students apply the pattern with teacher support. |
| 6 | **Independent Rebuild** | Students rebuild the pattern on a new problem with less help. |
| 7 | **Talk Robin 2 + Evidence** | Students explain their rebuild and submit proof of learning. |

## Guided Notes During the Video

Students complete the following while watching:

```text
Video title/topic:

Three key terms:
1.
2.
3.

The main problem or question explained by the teacher:

One example from the video:

One point I understood:

One point I am still confused about:

NOAI syllabus connection:
A. Python / code reading
B. AI foundations
C. data processing
D. sklearn / PyTorch / application

Rebuild pattern:
Input:
Process / model:
Output:
Evidence:
```

## Timing Rules for a 75-Minute Club Session

### If the video is 25 minutes or shorter

| Time | Block |
|---|---|
| 0–25 min | Skill Warm-Up: full video + guided notes |
| 25–32 min | Talk Robin 1 |
| 32–40 min | Entry Check |
| 40–50 min | Core Pattern |
| 50–62 min | Guided Practice |
| 62–70 min | Independent Rebuild |
| 70–75 min | Talk Robin 2 + Evidence |

### If the video is 25–45 minutes

| Time | Block |
|---|---|
| 0–40 min | Skill Warm-Up: full video + guided notes |
| 40–47 min | Talk Robin 1 |
| 47–53 min | Entry Check |
| 53–61 min | Core Pattern |
| 61–68 min | Guided Practice |
| 68–72 min | Independent Rebuild |
| 72–75 min | Talk Robin 2 + Evidence |

### If the video is longer than 45 minutes

Use two club sessions.

Session 1: full viewing, guided notes, first discussion, entry check, and teacher summary.

Session 2: review the notes, complete the entry check again, extract the core pattern, complete guided practice, independent rebuild, and evidence submission.

## Required Evidence

Each full-video lesson must produce at least four pieces of evidence:

1. completed video guided notes;
2. Entry Check answers;
3. Guided Practice work;
4. Independent Rebuild work;
5. Talk Robin 2 explanation or written reflection.

## Non-Negotiable Rule

A full Bohrium video can take more time than an ordinary warm-up, but it does not replace the classroom flow. The lesson still ends with student explanation and evidence, not with simply finishing the video.
