# Lesson 04 — Round 1 Overfitting/Regularisation Scenario Explanations

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read short overfitting and underfitting scenarios. |
| 8–15 min | Talk Robin 1 | Explain which scenario is which. |
| 15–22 min | Entry Check | Match remedies to problems. |
| 22–35 min | Core Pattern | Teacher models symptom → diagnosis → evidence → remedy. |
| 35–53 min | Guided Practice | Write supported Round 1 explanations. |
| 53–67 min | Independent Rebuild | Create one scenario and correction. |
| 67–75 min | Talk Robin 2 + Evidence | Submit short answer and distractor explanation. |

## Core Pattern

```text
Observed scores → diagnosis → reason → regularisation/split/data remedy → expected effect
```

## Evidence

Submit two explanations, one original scenario, and one misconception correction.
