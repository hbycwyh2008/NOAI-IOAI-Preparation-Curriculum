# Lesson 03 — Validation Curves, Data Leakage, and Model Selection

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect train/validation curves. |
| 8–15 min | Talk Robin 1 | Discuss overfitting, underfitting, and leakage clues. |
| 15–22 min | Entry Check | Diagnose two curve patterns. |
| 22–35 min | Core Pattern | Teacher models split → train curve → validation curve → diagnosis → remedy. |
| 35–53 min | Guided Practice | Complete supported curve/leakage scenarios. |
| 53–67 min | Independent Rebuild | Design a leakage-safe validation plan. |
| 67–75 min | Talk Robin 2 + Evidence | Submit diagnosis and plan. |

## Core Pattern

```text
Split design → training score → validation score → gap pattern → leakage check → model decision
```

## Evidence

Submit a curve diagnosis, leakage warning, and validation plan.
