# Lesson 03 — Mel-Spectrogram to Image-Classification Bridge

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare waveform, spectrogram, and Mel-spectrogram views. |
| 8–15 min | Talk Robin 1 | Explain why audio can become an image-like task. |
| 15–22 min | Entry Check | Identify time axis, frequency axis, and intensity. |
| 22–35 min | Core Pattern | Teacher models audio → feature image → classifier → evaluation. |
| 35–53 min | Guided Practice | Complete supported spectrogram interpretation. |
| 53–67 min | Independent Rebuild | Design a Mel-based classifier plan. |
| 67–75 min | Talk Robin 2 + Evidence | Submit bridge explanation. |

## Core Pattern

```text
Audio waveform → spectrogram/Mel feature → image-like tensor → classifier → metric/error analysis
```

## Evidence

Submit spectrogram annotation, bridge explanation, and classifier plan.
