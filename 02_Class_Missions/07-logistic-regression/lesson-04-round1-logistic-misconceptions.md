# Lesson 04 — Logistic Regression Misconceptions and Round 1 Explanations

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read common wrong claims about logistic regression. |
| 8–15 min | Talk Robin 1 | Explain why one claim is wrong. |
| 15–22 min | Entry Check | Correct three misconceptions. |
| 22–35 min | Core Pattern | Teacher models claim → correction → evidence → example. |
| 35–53 min | Guided Practice | Write supported Round 1 short answers. |
| 53–67 min | Independent Rebuild | Create a distractor and correction. |
| 67–75 min | Talk Robin 2 + Evidence | Explain final answer. |

## Core Pattern

```text
Misleading claim → identify hidden assumption → correct concept → example/evidence
```

## Evidence

Submit three corrections, one original distractor, and one Round 1-style explanation.
