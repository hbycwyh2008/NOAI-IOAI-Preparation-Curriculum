# 北京市十一学校《中学机器学习十五讲》Lesson 02 — 第一讲：人工智能的定义

**Video time:** 40:09  
**Class duration:** 70 minutes

## 1. Skill Warm-Up

Watch the full video and record: artificial-intelligence definition, one artificial-intelligence example, one non-artificial-intelligence example, and one boundary case.

## 2. Talk Robin 1

Explain why a system should or should not be called artificial intelligence.

## 3. Entry Check

1. Give one artificial-intelligence example and justify it.
2. Give one non-artificial-intelligence example and justify it.
3. What makes a boundary case hard?

## 4. Core Pattern

```text
System claim → capability → learning/reasoning behaviour → evidence → artificial-intelligence/non-artificial-intelligence boundary
```

## 5. Guided Practice

Classify several scenarios as artificial intelligence, not artificial intelligence, or ambiguous. Explain the evidence.

## 6. Independent Rebuild

Create a new boundary case and write a Round 1-style explanation.

## 7. Talk Robin 2 + Evidence

Submit notes, scenario classification, boundary case, and explanation.
