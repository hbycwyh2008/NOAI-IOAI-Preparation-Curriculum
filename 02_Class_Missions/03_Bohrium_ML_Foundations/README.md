# 03 — Bohrium Machine-Learning Foundations

**Scheduled sessions:** 19–32  
**Primary course:** 北京市十一学校《中学机器学习十五讲》 on Bohrium

This fourteen-session sequence is completed **before Andrew Ng Machine Learning Specialization**. It establishes Chinese-language concepts, task vocabulary, and Round 1 reasoning.

## Sequence

1. Course map and evidence expectations
2. Definition of artificial intelligence
3. Artificial-intelligence history, schools, and Turing Test
4. Connectionism and machine learning
5. Object-oriented programming and machine-learning libraries
6. Machine-learning workflow and training paradigms
7. Classification and logistic regression
8. Optimisation and gradient descent
9. Neural networks and backpropagation
10. K-nearest neighbours and Bayes reasoning
11. Support vector machines and margins
12. Entropy, decision trees, multiclass learning, and ensembles
13. Unsupervised learning and reinforcement learning
14. Deep neural networks and the bridge to Round 2

## Gate

Students can recognise classification, regression, clustering, and reinforcement-learning scenarios; distinguish training from inference; and explain the roles of data, model, loss, optimisation, prediction, and evaluation.
