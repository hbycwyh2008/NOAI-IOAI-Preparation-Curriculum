# Session 38 — Language Processing and Understanding

**Class duration:** 70 minutes  
**Required reading before class:** Chapters 11–13  
**Essential question:** When a machine produces fluent language, what has it demonstrated?

## Required Mastery

Students must be able to:

1. Explain the intuition that words appearing in similar contexts can receive similar representations.
2. Explain the purpose of word vectors or embeddings.
3. Describe translation as input-sequence encoding, internal representation, and output-sequence decoding.
4. Identify ambiguity, reference, irony, implied meaning, culture, and world knowledge as language challenges.
5. Distinguish grammatical generation, common-pattern completion, contextual reasoning, and understanding of speaker intent.
6. Explain how question-answering systems may use statistical patterns, retrieval clues, or learned associations.
7. Explain why fluency can cause people to overestimate factual reliability and understanding.
8. Design counterexamples, paraphrases, and context changes to test a language system.
9. Avoid the opposite error of assuming that a system without human-like understanding has no useful capabilities.

## Misconceptions to Reject

- Fluent language is necessarily factually correct.
- A correct answer proves understanding of the reasoning process.
- Language meaning can be reduced to word order without world knowledge.
- A model is either fully understanding or completely useless.

## Core Pattern

```text
linguistic form
→ contextual representation
→ generated or selected output
→ apparent meaning
→ understanding test
```

## 70-Minute Learning Cycle

| Time | Block | Required student action |
|---:|---|---|
| 0–7 | **Skill Warm-Up** | Sort questions by whether they require surface pattern, reference resolution, common sense, or causal reasoning. |
| 7–14 | **Talk Robin 1** | Compare one language-system success with one challenge from the reading. |
| 14–20 | **Entry Check** | Explain the basic purpose of an embedding and one thing it does not guarantee. |
| 20–32 | **Core Pattern** | Separate fluent output from evidence of grounded understanding. |
| 32–48 | **Guided Practice** | Design three questions: one answerable by common text patterns, one requiring reference resolution, and one requiring physical or social common sense. |
| 48–62 | **Independent Rebuild** | Build a language-capability ladder from word association through grammatical generation, translation, question answering, contextual reasoning, and grounded understanding. Add a test and an unsupported claim for each level. |
| 62–70 | **Talk Robin 2 + Evidence** | Use the ladder to evaluate one answer produced by a language system. |

## Exit Evidence

Explain how an answer can be correct while still providing insufficient evidence that the system understood the question.

## Gate

The student must identify both the demonstrated language capability and at least one stronger capability that remains untested.
