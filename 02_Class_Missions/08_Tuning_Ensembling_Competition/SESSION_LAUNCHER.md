## Non-Negotiable Order

```text
diagnose
→ tune
→ compare stable single models
→ ensemble only complementary valid models
→ execute from a fresh environment
→ validate submission
→ write the postmortem
```

## Phase Gate

Students complete a trustworthy end-to-end workflow, preserve validation integrity, produce a valid submission from a fresh runtime, and defend whether tuning or ensembling actually improved the system.
