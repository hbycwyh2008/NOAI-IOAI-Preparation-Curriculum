# 06 — Andrew Ng Deep Learning and PyTorch

**Scheduled sessions:** 56–67  
**Concept spine:** Deep Learning Specialization  
**Implementation spine:** PyTorch courses and official tutorials

Do not finish all Andrew Ng videos first and postpone coding. Pair each concept with an implementation and a typical task.

## Paired Sequence

1. Deep-learning map, tensor shapes, and baseline discipline
2. Forward propagation and PyTorch tensors/`nn.Module`
3. Backpropagation, autograd, and the complete training loop
4. Initialisation, learning rate, optimisers, BatchNorm, Dropout, and regularisation
5. Convolutional-neural-network concepts and shape reasoning
6. PyTorch image-classification task
7. Transfer learning and augmentation
8. Recurrent neural networks and long short-term memory networks
9. PyTorch text or time-series classification
10. Attention and Transformer intuition
11. Audio or multimodal task
12. Deep-learning capstone: simple baseline versus deep model, errors, cost, and limits

## Lesson Library Modules

`12-neural-network-foundations`, `13-backprop-optimization`, `14-cnn-foundations`, `19-pytorch-foundations`, `20-computer-vision`, `21-nlp-sequence-models`, `22-audio-speech`, and `23-llm-generative-ai`.

## Non-Negotiable Comparison

Every domain task keeps a simple or classical baseline. Students compare validation quality, errors, training cost, inference cost, data demand, and interpretability before claiming the deep model is better.

## Gate

Students can write a fresh PyTorch training/validation loop, reason about tensor shapes and dtypes, diagnose overfitting, save the best checkpoint, and compare a deep model with a trustworthy baseline.
