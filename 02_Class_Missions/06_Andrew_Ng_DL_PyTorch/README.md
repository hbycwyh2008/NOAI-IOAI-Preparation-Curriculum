## Delivery Rule

Do not finish all Andrew Ng videos first and postpone coding. Pair each concept with PyTorch, shape reasoning, a simple baseline, a typical task, and error analysis.

## Required Comparison

Every domain task keeps a simple or classical baseline. Students compare validation quality, errors, training cost, inference cost, data demand, and interpretability before claiming the deep model is better.

## Gate

Students write a fresh PyTorch training/validation loop, reason about tensor shapes and dtypes, diagnose overfitting or optimisation failure, save the best checkpoint, and compare a deep model with a trustworthy baseline.
