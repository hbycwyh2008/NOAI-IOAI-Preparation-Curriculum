# Lesson 06 — Image Error Analysis, Class Imbalance, and Submission Strategy

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect wrong image predictions. |
| 8–15 min | Talk Robin 1 | Discuss error patterns. |
| 15–22 min | Entry Check | Sort errors by cause. |
| 22–35 min | Core Pattern | Teacher explains error analysis → hypothesis → controlled change → submission. |
| 35–53 min | Guided Practice | Build an image error-analysis table. |
| 53–67 min | Independent Rebuild | Propose one controlled improvement. |
| 67–70 min | Talk Robin 2 + Evidence | Submit error table and improvement memo. |

## Core Pattern

```text
Wrong predictions → Error category → Hypothesis → Controlled fix → Validation/submission evidence
```

## Required Evidence

1. Image error-analysis table.
2. One class-imbalance observation.
3. One controlled improvement proposal.
