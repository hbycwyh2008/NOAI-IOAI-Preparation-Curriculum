# Lesson 07 — PyTorch Round 2 Mini-Project and Fresh-Runtime Validation

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review mini-project task, metric, and runtime constraints. |
| 8–15 min | Talk Robin 1 | Discuss baseline and failure risks. |
| 15–22 min | Entry Check | Identify dataset, model, loss, metric, and validation split. |
| 22–35 min | Core Pattern | Teacher models mini-project workflow. |
| 35–53 min | Guided Practice | Build supported baseline. |
| 53–67 min | Independent Rebuild | Rebuild or modify one component independently. |
| 67–75 min | Talk Robin 2 + Evidence | Submit fresh-run validation evidence. |

## Core Pattern

```text
Task → Dataset/DataLoader → model → train/validate → save/checkpoint → fresh runtime → report
```

## Evidence

Submit baseline code, metric output, fresh-run record, and one improvement plan.
