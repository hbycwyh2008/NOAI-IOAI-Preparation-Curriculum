# Curriculum Governance

These files are for teachers and maintainers, not the daily student route.

- `Class_Mission_Resource_Architecture.md` — resource roles and structural rules
- `Lesson_Distribution_Audit.md` — lesson-bank counts and structural coverage

The canonical teaching order is maintained in `02_Class_Missions/README.md` and the phase folders. The lesson library is audited for availability and structure but is not automatically scheduled.
