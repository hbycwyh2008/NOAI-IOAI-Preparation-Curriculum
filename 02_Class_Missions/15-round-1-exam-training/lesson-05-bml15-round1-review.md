# Lesson 05 — BML15 Full Video: Round 1 A/B Review

**Duration:** 75 minutes, or two 75-minute sessions if the assigned Bohrium video is longer than 45 minutes.

**Official-aligned resource:** 北京市十一学校《中学机器学习十五讲》

**Bohrium link:** https://www.bohrium.com/courses/5963419225/content?file=8496

**Placement:** This lesson is a Round 1 review lesson. Use it after students have studied Python foundations and basic AI/ML concepts, before full paper-test mocks.

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–40 min | Skill Warm-Up | Watch the full assigned Bohrium video and complete Round 1 guided notes. If the video exceeds 45 minutes, split into two club sessions. |
| 40–47 min | Talk Robin 1 | Explain which Round 1 topics appeared in the video. |
| 47–53 min | Entry Check | Answer paper-style concept and code-reading questions. |
| 53–61 min | Core Pattern | Convert video explanations into paper-test answer structures. |
| 61–68 min | Guided Practice | Complete supported multiple-choice, short-answer, and calculation prompts. |
| 68–72 min | Independent Rebuild | Write one new Round 1 question based on the video. |
| 72–75 min | Talk Robin 2 + Evidence | Explain and submit evidence. |

## 1. Skill Warm-Up

Watch the full assigned Bohrium video.

While watching, mark every idea that could become a Round 1 paper-test question.

```text
Video topic:

Round 1 concepts mentioned:
1.
2.
3.

Python / code-reading connection:

AI foundations connection:

Machine-learning concept connection:

One possible paper-test question inspired by the video:
```

## 2. Talk Robin 1

Partner discussion:

```text
This video could be tested in Round 1 because ...
The most testable concept is ...
The easiest distractor or misconception is ...
```

## 3. Entry Check

Answer individually:

1. Define one key term from the video in one sentence.
2. Give one example and one non-example.
3. Write one multiple-choice distractor that a careless student might choose.
4. Explain why that distractor is wrong.

## 4. Core Pattern

Teacher models how to turn video learning into paper-test answers:

```text
Concept → Example → Misconception → Evidence / Calculation / Code Trace
```

## 5. Guided Practice

Complete one supported Round 1 item in each format:

1. multiple choice;
2. short answer;
3. scenario reasoning;
4. code-reading or calculation if applicable.

## 6. Independent Rebuild

Write your own Round 1 question from the video.

```text
Question:
Correct answer:
Wrong answer / distractor:
Why the wrong answer is tempting:
Why the correct answer is correct:
```

## 7. Talk Robin 2 + Evidence

Submit:

1. video guided notes;
2. Entry Check answers;
3. Guided Practice responses;
4. one original Round 1-style question;
5. one explanation of the misconception behind your distractor.
