# Lesson 10 — Error-Pattern Correction and Final Round 1 Readiness

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review personal error log. |
| 8–15 min | Talk Robin 1 | Explain one repeated mistake to a partner. |
| 15–22 min | Entry Check | Categorise errors by concept, calculation, code, or time. |
| 22–35 min | Core Pattern | Teacher models error pattern → root cause → practice prescription. |
| 35–53 min | Guided Practice | Correct representative errors. |
| 53–67 min | Independent Rebuild | Build a final readiness checklist. |
| 67–75 min | Talk Robin 2 + Evidence | Submit readiness decision. |

## Core Pattern

```text
Repeated error → root cause → targeted correction → retest evidence → readiness decision
```

## Evidence

Submit error-pattern table, corrected work, retest evidence, and readiness decision.
