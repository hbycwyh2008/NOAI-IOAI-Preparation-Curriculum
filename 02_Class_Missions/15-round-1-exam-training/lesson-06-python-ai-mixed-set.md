# Lesson 06 — Python and AI Concept Mixed Set

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Try 5 mixed Python/AI questions. |
| 8–15 min | Talk Robin 1 | Identify which questions are concept, trace, or scenario. |
| 15–22 min | Entry Check | Correct two common mistakes. |
| 22–35 min | Core Pattern | Teacher models classify question type → choose solving pattern. |
| 35–53 min | Guided Practice | Complete supported mixed set. |
| 53–67 min | Independent Rebuild | Write two new mixed questions. |
| 67–75 min | Talk Robin 2 + Evidence | Explain distractors and submit work. |

## Core Pattern

```text
Question type → clue words/code state → solving pattern → answer → distractor check
```

## Evidence

Submit answers, corrections, two original items, and distractor explanations.
