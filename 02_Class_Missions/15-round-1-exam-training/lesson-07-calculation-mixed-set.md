# Lesson 07 — Metric, Statistics, and Model-Selection Calculations

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Attempt three calculation items. |
| 8–15 min | Talk Robin 1 | Identify which formula or table is needed. |
| 15–22 min | Entry Check | Compute one metric and one statistics value. |
| 22–35 min | Core Pattern | Teacher models quantity identification and distractor checking. |
| 35–53 min | Guided Practice | Complete supported calculation set. |
| 53–67 min | Independent Rebuild | Create one calculation item. |
| 67–75 min | Talk Robin 2 + Evidence | Explain result and submit evidence. |

## Core Pattern

```text
Stem clue → target quantity → formula/table → substitution → interpretation → distractor check
```

## Evidence

Submit calculations, one formula note, one original item, and one distractor explanation.
