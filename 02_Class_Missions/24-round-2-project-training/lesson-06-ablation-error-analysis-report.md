# Lesson 06 — Ablation, Error Analysis, and Final Report

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect two model versions and score changes. |
| 8–15 min | Talk Robin 1 | Discuss what changed and why it may matter. |
| 15–22 min | Entry Check | Identify controlled vs uncontrolled experiment changes. |
| 22–35 min | Core Pattern | Teacher explains ablation → error analysis → final report. |
| 35–53 min | Guided Practice | Build an ablation table and error-analysis summary. |
| 53–67 min | Independent Rebuild | Write a final report skeleton for a new project. |
| 67–70 min | Talk Robin 2 + Evidence | Submit ablation table and report skeleton. |

## Core Pattern

```text
Baseline → One controlled change → Validation result → Error analysis → Decision → Final report
```

## Required Evidence

1. Ablation table.
2. Error-analysis summary.
3. Final report skeleton.
