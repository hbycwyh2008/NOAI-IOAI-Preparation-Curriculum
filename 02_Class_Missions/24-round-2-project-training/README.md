# 24 — Round 2 Project Training

This module prepares students for NOAI China Round 2 and IOAI-style applied tasks. It must contain enough lessons for task reading, baseline-first modelling, validation, controlled experiments, AI-assistant use, leaderboard reasoning, and final submission.

- [Lesson 02 — Baseline-first development and submission validation](lesson-02.md)

- [Lesson 05 — AI-assistant use, prompt log, and verification](lesson-05-ai-assistant-prompt-log-verification.md)
- [Lesson 06 — Ablation, error analysis, and final report](lesson-06-ablation-error-analysis-report.md)

## Minimum Evidence

Students should submit a task decomposition, data audit, baseline, validation memo, prompt log, controlled experiment table, error analysis, final submission, and postmortem.
