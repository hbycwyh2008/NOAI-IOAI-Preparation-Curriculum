# BML15 Lesson 01 — 第零讲：目录视频

**Video time:** 28:17  
**Class duration:** 70 minutes

## 1. Skill Warm-Up

Watch the full assigned video and complete guided notes: course map, three key terms, one personal goal, one confusion.

## 2. Talk Robin 1

Explain to a partner: what topics will this course cover, and which topics connect to NOAI Round 1 A/B?

## 3. Entry Check

1. What is the difference between watching a course and producing learning evidence?
2. Name three areas of machine learning mentioned or previewed.
3. Which future topic feels hardest and why?

## 4. Core Pattern

```text
Course map → topic cluster → NOAI connection → evidence requirement → personal study target
```

## 5. Guided Practice

Fill a learning-map table with columns: topic, example, NOAI link, evidence to submit.

## 6. Independent Rebuild

Create your own 4-week BML15 study map using the same evidence logic.

## 7. Talk Robin 2 + Evidence

Submit guided notes, learning map, personal goal, and one confusion to revisit.
