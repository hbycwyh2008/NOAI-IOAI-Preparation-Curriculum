# BML15 Lesson 02 — 第一讲：人工智能的定义

**Video time:** 40:09  
**Class duration:** 70 minutes

## 1. Skill Warm-Up

Watch the full video and record: AI definition, one AI example, one non-AI example, and one boundary case.

## 2. Talk Robin 1

Explain why a system should or should not be called AI.

## 3. Entry Check

1. Give one AI example and justify it.
2. Give one non-AI example and justify it.
3. What makes a boundary case hard?

## 4. Core Pattern

```text
System claim → capability → learning/reasoning behaviour → evidence → AI/non-AI boundary
```

## 5. Guided Practice

Classify several scenarios as AI, not AI, or ambiguous. Explain the evidence.

## 6. Independent Rebuild

Create a new boundary case and write a Round 1-style explanation.

## 7. Talk Robin 2 + Evidence

Submit notes, scenario classification, boundary case, and explanation.
