**Video time:** 48:48  
**Class duration:** 70 minutes

## 1. Skill Warm-Up

Watch the full video and record the relationship among data, model, training, and inference.

## 2. Talk Robin 1

Explain how a machine-learning system is different from a hand-written rule system.

## 3. Entry Check

1. What is training?
2. What is inference?
3. What evidence shows a model has learned something useful?

## 4. Core Pattern

```text
Data → model structure → training process → learned behaviour → inference → evaluation evidence
```

## 5. Guided Practice

Annotate a simple machine-learning workflow with input, output, model, training data, and evaluation evidence.

## 6. Independent Rebuild

Design a new machine-learning problem and rebuild the workflow without copying the example.

## 7. Talk Robin 2 + Evidence

Submit video notes, workflow annotation, rebuilt problem, and one training-versus-inference explanation.
