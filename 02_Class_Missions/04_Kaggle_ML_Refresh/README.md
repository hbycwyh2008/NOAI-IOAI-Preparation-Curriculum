# 04 — Kaggle Machine-Learning Refresh

**Scheduled sessions:** 33–37  
**Role:** practical rehearsal between Bohrium concepts and Andrew Ng theory

Kaggle Learn is used as a short workflow refresh. It is not the principal theory course and does not replace Andrew Ng Machine Learning Specialization.

## Five Sessions

1. Pandas refresh — features, labels, types, and missingness
2. Data visualisation refresh — diagnostic questions before plots
3. Intro to Machine Learning — split, decision-tree baseline, metric, prediction
4. Intermediate Machine Learning — missing values, categorical variables, pipelines, cross-validation, leakage
5. Mini Kaggle workflow — reproduce a baseline, make one controlled improvement, validate the submission, and write a postmortem

## Supporting Lesson Library Modules

- `16-numpy-pandas-matplotlib`
- `17-data-cleaning-feature-engineering`
- `18-sklearn-workflow`

## Gate

Students can execute and explain:

```text
X and y
→ split
→ preprocessing fitted on training data
→ baseline
→ validation metric
→ prediction
→ submission checks
```

Deep model theory, broad model comparison, and automated tuning are deliberately deferred.
