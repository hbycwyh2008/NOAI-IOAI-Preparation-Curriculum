# Lesson 03 — Probability, Distributions, Residuals, and Bias

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read a small prediction-error table. |
| 8–15 min | Talk Robin 1 | Discuss residuals and systematic error. |
| 15–22 min | Entry Check | Compute simple probability and residual values. |
| 22–35 min | Core Pattern | Teacher models distribution → prediction → residual → bias pattern. |
| 35–53 min | Guided Practice | Complete supported calculations. |
| 53–67 min | Independent Rebuild | Create a small example showing bias. |
| 67–75 min | Talk Robin 2 + Evidence | Explain evidence. |

## Core Pattern

```text
Observed values → expected pattern → prediction → residuals → systematic bias or noise
```

## Evidence

Submit calculations, one residual table, and one explanation of bias versus random error.
