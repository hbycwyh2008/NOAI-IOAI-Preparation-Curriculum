# Lesson 05 — Training, Inference, Labels, Features, and Evaluation Evidence

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect a model workflow diagram. |
| 8–15 min | Talk Robin 1 | Discuss which part is training and which part is inference. |
| 15–22 min | Entry Check | Identify features, labels, prediction, and evidence. |
| 22–35 min | Core Pattern | Teacher models dataset → training → learned model → inference → evaluation. |
| 35–53 min | Guided Practice | Annotate supported workflows. |
| 53–67 min | Independent Rebuild | Design a workflow for a new problem. |
| 67–75 min | Talk Robin 2 + Evidence | Explain the workflow and submit evidence. |

## Core Pattern

```text
Features + labels → training → model parameters → new input → prediction → evaluation evidence
```

## Evidence

Submit an annotated workflow, one rebuilt workflow, and one training-vs-inference explanation.
