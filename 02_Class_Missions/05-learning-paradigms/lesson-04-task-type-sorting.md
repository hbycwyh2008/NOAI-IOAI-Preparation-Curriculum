# Lesson 04 — Regression, Classification, Clustering, and Task-Type Sorting

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Sort short scenarios into task types. |
| 8–15 min | Talk Robin 1 | Explain the difference between labels and no labels. |
| 15–22 min | Entry Check | Identify regression, classification, and clustering. |
| 22–35 min | Core Pattern | Teacher models input → output type → label status → task type. |
| 35–53 min | Guided Practice | Complete supported NOAI scenario sorting. |
| 53–67 min | Independent Rebuild | Create three new scenarios. |
| 67–75 min | Talk Robin 2 + Evidence | Explain one tricky case. |

## Core Pattern

```text
Scenario → input data → desired output → label status → task type → evaluation evidence
```

## Evidence

Submit a scenario table, three created examples, and one explanation of a common distractor.
