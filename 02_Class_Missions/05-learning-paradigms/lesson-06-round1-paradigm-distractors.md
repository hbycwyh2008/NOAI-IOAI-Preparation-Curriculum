# Lesson 06 — Round 1 Learning-Paradigm Distractors and Scenario Explanations

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read tricky task-type distractors. |
| 8–15 min | Talk Robin 1 | Explain why one wrong answer is tempting. |
| 15–22 min | Entry Check | Classify four scenarios with reasons. |
| 22–35 min | Core Pattern | Teacher models evidence-based scenario classification. |
| 35–53 min | Guided Practice | Solve supported Round 1-style items. |
| 53–67 min | Independent Rebuild | Write one original distractor question. |
| 67–75 min | Talk Robin 2 + Evidence | Explain correct answer and distractor. |

## Core Pattern

```text
Scenario clues → output type → label status → learning paradigm → distractor trap
```

## Evidence

Submit scenario classifications, one original question, and one distractor explanation.
