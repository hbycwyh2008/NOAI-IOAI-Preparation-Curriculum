# Lesson 03 — Connectionism, Symbolism, Behaviourism, and Examples

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read short examples of AI approaches. |
| 8–15 min | Talk Robin 1 | Match examples to schools of thought. |
| 15–22 min | Entry Check | Define the three schools in one sentence each. |
| 22–35 min | Core Pattern | Teacher models idea → representation → example → limitation. |
| 35–53 min | Guided Practice | Complete an AI-school comparison table. |
| 53–67 min | Independent Rebuild | Classify a new AI scenario. |
| 67–75 min | Talk Robin 2 + Evidence | Explain classification and submit evidence. |

## Core Pattern

```text
AI claim → method used → school of thought → evidence → limitation
```

## Evidence

Submit a comparison table, one classified scenario, and one limitation explanation.
