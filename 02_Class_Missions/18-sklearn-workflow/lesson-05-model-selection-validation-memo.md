# Lesson 05 — Model Selection, Hyperparameter Search, and Validation Memo

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare model scores from several candidates. |
| 8–15 min | Talk Robin 1 | Discuss why the highest score may not be enough. |
| 15–22 min | Entry Check | Identify baseline, candidate model, metric, and validation design. |
| 22–35 min | Core Pattern | Teacher models compare → tune → validate → choose → justify. |
| 35–53 min | Guided Practice | Complete supported model-selection table. |
| 53–67 min | Independent Rebuild | Write a validation memo for a new task. |
| 67–75 min | Talk Robin 2 + Evidence | Defend model choice. |

## Core Pattern

```text
Baseline → candidate models → validation protocol → hyperparameter search → score + risk → model decision
```

## Evidence

Submit comparison table, tuned setting, validation memo, and model-choice justification.
