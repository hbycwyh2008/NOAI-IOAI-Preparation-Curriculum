# Mathematics Intuition Map for Andrew Ng ML

Mathematics is learned **just in time**, not as a disconnected prerequisite course.

| Model/topic | Required intuition | Best support |
|---|---|---|
| Linear regression | vectors, dot product, line slope, residual, derivative, gradient direction | 3Blue1Brown for vectors/calculus; StatQuest for regression |
| Multiple regression | matrix-shaped data, vectorisation, feature scale, contour and cost surface | 3Blue1Brown + Andrew Ng |
| Logistic regression | exponential, sigmoid, probability, logarithm, decision boundary, log loss | StatQuest + Andrew Ng |
| Regularisation | parameter magnitude, L1/L2 norms, bias–variance trade-off | StatQuest |
| Neural networks | matrix multiplication, weighted sums, composition, chain rule | 3Blue1Brown + Andrew Ng |
| Trees and ensembles | probability, impurity, entropy, averaging, variance reduction | StatQuest |
| KNN and K-means | coordinates, Euclidean distance, mean, centroid, iterative improvement | StatQuest |
| SVM | distance to a boundary, margin, support points | StatQuest / Bohrium |
| PCA | projection, variance direction, eigenvectors/eigenvalues as directions and scales | 3Blue1Brown + StatQuest |
| Anomaly detection | mean, variance, normal distribution, density, threshold | StatQuest |
| Recommenders | vectors, dot product, similarity, embeddings, matrix structure | 3Blue1Brown + Andrew Ng |

## Rule

Students do not need large symbolic derivations before modelling. They must explain what each mathematical object represents, predict the effect of a change, and connect the mathematics to model behaviour.
