# Lesson 04 — Distance Metrics, Scaling Effects, and Nearest-Neighbour Reasoning

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare distances before and after scaling. |
| 8–15 min | Talk Robin 1 | Discuss why one feature can dominate. |
| 15–22 min | Entry Check | Compute one Euclidean distance. |
| 22–35 min | Core Pattern | Teacher models raw features → scaling → distance → neighbour choice. |
| 35–53 min | Guided Practice | Complete supported KNN reasoning. |
| 53–67 min | Independent Rebuild | Create a new distance-based classification case. |
| 67–75 min | Talk Robin 2 + Evidence | Explain scaling decision. |

## Core Pattern

```text
Feature values → scale check → distance calculation → nearest examples → prediction
```

## Evidence

Submit distance calculations, scaling comparison, and one KNN scenario explanation.
