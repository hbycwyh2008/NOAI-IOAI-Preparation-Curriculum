# Model Recognition Routine

Use this routine in every model lesson and mixed drill.

1. What is one row or sample?
2. What is the input X?
3. What is the target y?
4. Are labels available during training?
5. What must the model output: a number, class, probability, group, ranking, sequence, or generated object?
6. What task family is this: regression, classification, clustering, dimensionality reduction, anomaly detection, recommendation, reinforcement learning, or generation?
7. What is the simplest valid baseline?
8. Which metric reflects the real error cost?
9. Which two model families are reasonable candidates?
10. What assumption or limitation could make each candidate fail?

## Required Answer Format

```text
X:
y:
labels:
output:
task:
baseline:
metric:
candidate models:
likely limitation:
```

Do not select a model from keywords alone. Decide from label availability and required output.
