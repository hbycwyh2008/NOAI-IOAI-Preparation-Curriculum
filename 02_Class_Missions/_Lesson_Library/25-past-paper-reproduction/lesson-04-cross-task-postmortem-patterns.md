# Lesson 04 — Cross-Task Postmortem and Reusable Competition Patterns

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review three reproduced task summaries. |
| 8–15 min | Talk Robin 1 | Discuss which strategies transferred across tasks. |
| 15–22 min | Entry Check | Identify baseline, validation, feature/model, and failure pattern. |
| 22–35 min | Core Pattern | Teacher models compare tasks → extract pattern → write postmortem. |
| 35–53 min | Guided Practice | Complete supported cross-task comparison. |
| 53–67 min | Independent Rebuild | Write a reusable competition pattern. |
| 67–75 min | Talk Robin 2 + Evidence | Submit postmortem. |

## Core Pattern

```text
Task A/B/C → shared constraint → solution pattern → failure mode → reusable checklist
```

## Evidence

Submit cross-task comparison, one reusable pattern, and one postmortem paragraph.
