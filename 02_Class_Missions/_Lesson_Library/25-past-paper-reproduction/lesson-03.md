# Mission 25.3 — Reproduce an Audio or Image Task

**Duration:** 180 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–15 min | Task reading and rules | Identify target, metric, files, constraints, and submission schema. |
| 15–35 min | Data audit | Inspect shapes, labels, missing values, modality, and leakage risks. |
| 35–60 min | Baseline plan | Choose the simplest valid structural or learned baseline and validation design. |
| 60–105 min | Baseline build | Produce the first working model and predictions. |
| 105–120 min | First submission check | Validate order, shape, dtypes, and metric. |
| 120–150 min | Controlled improvement | Run one justified preprocessing, augmentation, feature, or model change. |
| 150–170 min | Error analysis | Inspect failures by class, quality, length, resolution, or other task-relevant category. |
| 170–180 min | Submission and post-mortem | Save notebook, predictions, experiment log, and reflection. |

## Required Resource

Official teacher-supplied NOAI task package. Use only authorised task files and official rules.

## Learning Targets

- inspect raw multimodal data;
- choose a structural or learned baseline;
- control preprocessing and augmentation;
- analyse failure cases;
- reproduce a valid result before comparing with a reference route.

## Independent Task

Reproduce the task and write a post-mortem comparing your route with the reference route.

## Required Evidence

Submit:

1. task-recognition sheet;
2. modality-specific data audit;
3. baseline notebook and validation result;
4. preprocessing or transform specification;
5. validated submission file;
6. one controlled-improvement record;
7. failure-case table with examples;
8. fresh-runtime record;
9. post-mortem explaining what transferred to future tasks.
