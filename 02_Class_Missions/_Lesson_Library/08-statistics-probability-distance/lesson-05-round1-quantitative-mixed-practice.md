# Lesson 05 — Round 1 Quantitative Mixed Practice

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Try a mixed statistics/distance calculation set. |
| 8–15 min | Talk Robin 1 | Identify which formula or reasoning pattern is needed. |
| 15–22 min | Entry Check | Solve two short calculations. |
| 22–35 min | Core Pattern | Teacher models identify quantity → formula → substitution → interpretation. |
| 35–53 min | Guided Practice | Complete supported Round 1 mixed items. |
| 53–67 min | Independent Rebuild | Write one original quantitative item. |
| 67–75 min | Talk Robin 2 + Evidence | Explain solution and distractor. |

## Core Pattern

```text
Question clue → target quantity → formula/reasoning → calculation → interpretation → distractor check
```

## Evidence

Submit calculations, one original item, and one distractor explanation.
