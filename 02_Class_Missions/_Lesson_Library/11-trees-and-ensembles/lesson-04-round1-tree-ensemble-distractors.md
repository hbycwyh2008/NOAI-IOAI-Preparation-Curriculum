# Lesson 04 — Round 1 Tree/Ensemble Calculations and Distractors

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect a tiny tree split and ensemble claim. |
| 8–15 min | Talk Robin 1 | Discuss why trees overfit and forests reduce variance. |
| 15–22 min | Entry Check | Complete one split/purity item. |
| 22–35 min | Core Pattern | Teacher models split criterion → tree behaviour → ensemble effect. |
| 35–53 min | Guided Practice | Solve supported Round 1 tree/ensemble items. |
| 53–67 min | Independent Rebuild | Write one distractor question. |
| 67–75 min | Talk Robin 2 + Evidence | Explain correct answer and trap. |

## Core Pattern

```text
Data split → impurity/evidence → tree decision → ensemble method → generalisation effect
```

## Evidence

Submit calculation work, one tree/forest/boosting comparison, and one distractor explanation.
