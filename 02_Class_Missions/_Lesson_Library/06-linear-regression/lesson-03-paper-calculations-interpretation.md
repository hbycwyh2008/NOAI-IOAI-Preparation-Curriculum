# Lesson 03 — Linear Regression Paper Calculations and Interpretation

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read a tiny regression table. |
| 8–15 min | Talk Robin 1 | Discuss prediction, residual, and error. |
| 15–22 min | Entry Check | Compute two residuals. |
| 22–35 min | Core Pattern | Teacher models prediction → residual → squared error → interpretation. |
| 35–53 min | Guided Practice | Complete supported paper calculations. |
| 53–67 min | Independent Rebuild | Create and solve a small regression calculation. |
| 67–75 min | Talk Robin 2 + Evidence | Explain result and submit work. |

## Core Pattern

```text
x → prediction y_hat → compare with y → residual → error summary → model interpretation
```

## Evidence

Submit residual calculations, one interpretation paragraph, and one original mini-problem.
