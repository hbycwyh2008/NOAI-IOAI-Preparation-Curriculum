# Lesson 04 — Regression Baseline, Error Analysis, and Round 2 Bridge

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare a simple baseline and a fitted regression model. |
| 8–15 min | Talk Robin 1 | Discuss when a model is better than a baseline. |
| 15–22 min | Entry Check | Identify baseline, metric, and error pattern. |
| 22–35 min | Core Pattern | Teacher models baseline → model → metric → error analysis → decision. |
| 35–53 min | Guided Practice | Complete a supported regression comparison. |
| 53–67 min | Independent Rebuild | Design a baseline for a new task. |
| 67–75 min | Talk Robin 2 + Evidence | Submit comparison and explanation. |

## Core Pattern

```text
Task → naive baseline → regression model → metric comparison → error pattern → next experiment
```

## Evidence

Submit a baseline decision, comparison table, and one error-analysis note.
