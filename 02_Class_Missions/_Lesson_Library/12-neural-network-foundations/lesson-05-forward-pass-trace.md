# Lesson 05 — Forward-Pass Hand Trace and Paper-Test Explanation

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read a tiny network with given weights. |
| 8–15 min | Talk Robin 1 | Predict where calculation errors may happen. |
| 15–22 min | Entry Check | Compute one neuron output. |
| 22–35 min | Core Pattern | Teacher models a forward-pass trace. |
| 35–53 min | Guided Practice | Complete a supported forward-pass table. |
| 53–67 min | Independent Rebuild | Trace a new tiny network independently. |
| 67–70 min | Talk Robin 2 + Evidence | Submit trace and explanation. |

## Core Pattern

```text
Input values → Weighted sum → Bias → Activation → Next layer → Prediction
```

## Required Evidence

1. Completed forward-pass table.
2. One explanation of activation role.
3. One corrected calculation error.
