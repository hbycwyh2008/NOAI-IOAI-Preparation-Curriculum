# Lesson 04 — Parameter Counting and Layer-Shape Reasoning

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect a small neural-network architecture. |
| 8–15 min | Talk Robin 1 | Discuss where parameters come from. |
| 15–22 min | Entry Check | Count parameters for one dense layer. |
| 22–35 min | Core Pattern | Teacher explains input shape → weight matrix → bias → output shape. |
| 35–53 min | Guided Practice | Complete parameter-count and shape tables. |
| 53–67 min | Independent Rebuild | Design a small MLP and count parameters. |
| 67–70 min | Talk Robin 2 + Evidence | Submit shape/parameter table. |

## Core Pattern

```text
Input dimension → Output units → Weights + bias → Parameter count → Output shape
```

## Required Evidence

1. Dense-layer parameter calculation.
2. Shape ledger.
3. One student-designed network with parameter count.
