# 17 — Data Cleaning and Feature Engineering

This module prepares students for real Round 2 datasets where performance depends on leakage prevention, robust preprocessing, feature design, and defensible experiment records.

## Minimum Evidence

Students should submit a cleaning memo, leakage warning, encoding/scaling pipeline, feature table, ablation record, and short decision memo.
