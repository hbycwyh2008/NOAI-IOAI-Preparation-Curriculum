# Lesson 05 — Round 2 Audio Reproduction and Submission Strategy

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review an audio task statement and sample submission. |
| 8–15 min | Talk Robin 1 | Discuss baseline and metric. |
| 15–22 min | Entry Check | Identify input, output, split, feature, and metric. |
| 22–35 min | Core Pattern | Teacher models task → feature → baseline → validation → submission. |
| 35–53 min | Guided Practice | Complete supported reproduction plan. |
| 53–67 min | Independent Rebuild | Create a submission strategy for a new audio task. |
| 67–75 min | Talk Robin 2 + Evidence | Submit plan and risk note. |

## Core Pattern

```text
Task statement → audio features → baseline model → validation metric → submission format → postmortem
```

## Evidence

Submit task decomposition, baseline plan, submission checklist, and postmortem note.
