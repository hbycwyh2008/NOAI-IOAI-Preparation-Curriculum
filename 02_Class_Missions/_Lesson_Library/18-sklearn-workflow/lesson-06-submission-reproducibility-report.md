# Lesson 06 — Submission File, Reproducibility, and Round 2 Baseline Report

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect sample submission and prediction format. |
| 8–15 min | Talk Robin 1 | Discuss format errors and reproducibility risks. |
| 15–22 min | Entry Check | Validate column names, row count, and value range. |
| 22–35 min | Core Pattern | Teacher models train → predict → validate submission → fresh run → report. |
| 35–53 min | Guided Practice | Complete supported submission checklist. |
| 53–67 min | Independent Rebuild | Write a baseline report for a new task. |
| 67–75 min | Talk Robin 2 + Evidence | Submit checked file and report. |

## Core Pattern

```text
Model output → sample format → submission validation → fresh runtime → baseline report → next experiment
```

## Evidence

Submit submission check, fresh-run record, baseline report, and next-step experiment idea.
