# Lesson 08 — Neural Network, CNN, and Optimisation Short Answers

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read three short-answer prompts. |
| 8–15 min | Talk Robin 1 | Identify what each answer must include. |
| 15–22 min | Entry Check | Write one sentence for forward/loss/backward. |
| 22–35 min | Core Pattern | Teacher models definition → role → example → misconception. |
| 35–53 min | Guided Practice | Draft supported NN/CNN/optimizer answers. |
| 53–67 min | Independent Rebuild | Write one answer from scratch. |
| 67–75 min | Talk Robin 2 + Evidence | Peer explain and revise. |

## Core Pattern

```text
Term → role in model/training → evidence/example → common wrong idea → corrected answer
```

## Evidence

Submit three short answers, one revised answer, and one misconception correction.
