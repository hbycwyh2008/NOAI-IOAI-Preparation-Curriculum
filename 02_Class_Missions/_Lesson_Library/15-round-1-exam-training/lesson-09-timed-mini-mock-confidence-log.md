# Lesson 09 — Timed Round 1 Mini-Mock and Confidence Log

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review test rules and confidence scale. |
| 8–15 min | Talk Robin 1 | Set personal risk targets. |
| 15–45 min | Entry Check / Mini-Mock | Complete timed mixed mini-mock. |
| 45–55 min | Core Pattern | Teacher models confidence/error coding. |
| 55–63 min | Guided Practice | Correct high-value errors. |
| 63–70 min | Independent Rebuild | Write correction plan. |
| 70–75 min | Talk Robin 2 + Evidence | Submit score and plan. |

## Core Pattern

```text
Answer → confidence rating → result → error type → correction action → retake priority
```

## Evidence

Submit answer sheet, score, confidence log, and top-three correction plan.
