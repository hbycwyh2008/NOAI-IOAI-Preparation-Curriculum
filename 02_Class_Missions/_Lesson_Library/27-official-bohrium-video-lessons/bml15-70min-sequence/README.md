# 北京市十一学校《中学机器学习十五讲》— 14 × 70-Minute Lesson Sequence

This folder turns 北京市十一学校《中学机器学习十五讲》 into **14 teachable 70-minute club lessons**.

The sequence is mainly for **NOAI Round 1 A/B** preparation: artificial-intelligence foundations, machine-learning concepts, Python/library awareness, paper-test explanations, and concept-to-evidence reasoning.

## Required Flow

Every lesson uses the same classroom cycle:

**Skill Warm-Up → Talk Robin 1 → Entry Check → Core Pattern → Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence**

The video is the Skill Warm-Up. Watching the video is not the final product. Each lesson must end with a student rebuild and evidence.
