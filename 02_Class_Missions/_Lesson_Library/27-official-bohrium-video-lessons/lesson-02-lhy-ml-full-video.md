# Mission 27.2 — 台湾大学李宏毅《机器学习》内容精选版完整视频

**Duration:** 75 minutes, or two 75-minute sessions if the assigned video is longer than 45 minutes.

**Official-aligned resource:** 台湾大学李宏毅《机器学习》内容精选版

**Bohrium link:** https://www.bohrium.com/courses/7890895681/content?file=2496

**Best use:** Round 2 C/D preparation: deeper machine-learning and deep-learning understanding before or after scikit-learn/PyTorch practice.

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–40 min | Skill Warm-Up | Watch the full assigned Bohrium video and complete guided notes. If the video exceeds 45 minutes, use Session 1 for full viewing and Session 2 for practice/rebuild. |

## 2. Talk Robin 1

Pair discussion prompts:

1. What did the video clarify about machine learning or deep learning?
2. Which part connects to actual model training or prediction?
3. Which part would be hard to implement in scikit-learn or PyTorch?
4. What question should we ask before coding?

## 3. Entry Check

Answer individually:

1. Define the key concept from the video in one sentence.
2. Identify the input, model, output, and evidence in the video example.
3. State whether the idea is mainly about data, model structure, training, evaluation, or deployment.
4. Write one implementation risk: shape error, leakage, overfitting, wrong metric, device issue, or misuse of an AI assistant.

## 4. Core Pattern

The teacher extracts one reusable machine-learning or deep-learning pattern from the video.

Use this structure:

```text
Data → Model → Training / Inference → Evaluation → Revision
```

Students annotate:

- what data representation is needed;
- what model or method is used;
- what training or inference step matters;
- how the result is evaluated;
- what controlled revision could improve it.

## 7. Talk Robin 2 + Evidence

Submit:

1. completed video notes;
2. Entry Check answers;
3. Guided Practice work;
4. Independent Rebuild work;
5. one oral or written explanation of the machine-learning or deep-learning pattern.

## Teacher Note

This mission should be used with actual modelling or notebook practice soon after the video. The video builds understanding; the evidence must show that students can apply and rebuild the idea.
