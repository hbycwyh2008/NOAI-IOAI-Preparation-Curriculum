# Mission 27.1 — 北京市十一学校《中学机器学习十五讲》完整视频：Machine-Learning Foundations

**Duration:** 75 minutes, or two 75-minute sessions if the assigned video is longer than 45 minutes.

**Official-aligned resource:** 北京市十一学校《中学机器学习十五讲》

**Bohrium link:** https://www.bohrium.com/courses/5963419225/content?file=8496

**Best use:** Round 1 A/B preparation: artificial-intelligence foundations, machine-learning concepts, Python-related reasoning, and paper-test preparation.

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–40 min | Skill Warm-Up | Watch the full assigned Bohrium video and complete guided notes. If the video exceeds 45 minutes, use Session 1 for full viewing and Session 2 for practice/rebuild. |
| 40–47 min | Talk Robin 1 | Explain what the teacher in the video was trying to teach and what remains confusing. |
| 47–53 min | Entry Check | Answer short concept and scenario questions. |

| 61–68 min | Guided Practice | Apply the pattern to a supported NOAI-style question. |

| 72–75 min | Talk Robin 2 + Evidence | Explain and submit evidence. |

## 2. Talk Robin 1

Pair discussion prompts:

1. What was the main idea of the video?
2. Which example made the idea clearer?
3. Which part still needs teacher clarification?
4. How could this idea appear in a Round 1 paper-test question?

## 3. Entry Check

Answer individually:

1. Define the key concept from the video in one sentence.
2. Give one example and one non-example.
3. Identify whether the idea belongs mostly to Python skills, artificial-intelligence foundations, data processing, or modelling.
4. Write one possible NOAI Round 1 short-answer question based on the video.

## 4. Core Pattern

The teacher extracts one reusable pattern from the video.

Use this structure:

```text
Problem → Input → Method / Model → Output → Evidence
```

Students annotate:

- what the problem is;
- what the data/input is;
- what method/model is used;
- what output is produced;
- what evidence proves the method works.

## 7. Talk Robin 2 + Evidence

Submit:

1. completed video notes;
2. Entry Check answers;
3. Guided Practice work;
4. Independent Rebuild work;
5. one oral or written explanation of the core pattern.

## Teacher Note

This mission is designed for full-video learning. Do not reduce the video to a short clip unless the teacher intentionally changes the lesson goal.
