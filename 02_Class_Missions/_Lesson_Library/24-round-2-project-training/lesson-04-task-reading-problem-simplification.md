# Lesson 04 — Task Reading and Problem Simplification

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read a Round 2-style task brief. |
| 8–15 min | Talk Robin 1 | Discuss what the task is really asking. |
| 15–22 min | Entry Check | Identify input, output, metric, and constraints. |
| 22–35 min | Core Pattern | Teacher explains task brief → simplified ML problem. |
| 35–53 min | Guided Practice | Decompose a supported task into solvable parts. |
| 53–67 min | Independent Rebuild | Simplify a new task independently. |
| 67–70 min | Talk Robin 2 + Evidence | Submit decomposition and simplification. |

## Core Pattern

```text
Story/task brief → Input/output → Metric → Constraints → Simplified ML problem → Baseline plan
```

## Required Evidence

1. Task decomposition.
2. Simplified problem statement.
3. Baseline plan.
