# Lesson 05 — AI-Assistant Use, Prompt Log, and Verification

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect examples of helpful and unsafe AI-assistant use. |
| 8–15 min | Talk Robin 1 | Discuss what the student must still decide independently. |
| 15–22 min | Entry Check | Classify AI use as acceptable, risky, or unacceptable. |
| 22–35 min | Core Pattern | Teacher explains human decision → AI help → verification → prompt log. |
| 35–53 min | Guided Practice | Rewrite poor prompts into verifiable prompts. |
| 53–67 min | Independent Rebuild | Create a prompt log and verification plan for a new task. |
| 67–70 min | Talk Robin 2 + Evidence | Submit prompt log and verification note. |

## Core Pattern

```text
Human plan → AI-assisted implementation/debugging → Independent verification → Prompt log → Evidence
```

## Required Evidence

1. AI-use classification table.
2. Improved prompt.
3. Prompt log.
4. Verification plan.
