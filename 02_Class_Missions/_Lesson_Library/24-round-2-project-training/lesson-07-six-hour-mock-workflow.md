# Lesson 07 — Six-Hour Mock Workflow and Time Management

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review the structure of a 6-hour Round 2 task block. |
| 8–15 min | Talk Robin 1 | Discuss how time is lost in open-ended tasks. |
| 15–22 min | Entry Check | Build a time budget for task reading, baseline, experiments, submission. |
| 22–35 min | Core Pattern | Teacher explains 6-hour workflow: baseline first, controlled experiments, final submission. |
| 35–53 min | Guided Practice | Plan a 6-hour strategy for a supported mock. |
| 53–67 min | Independent Rebuild | Write an independent time plan for a new task. |
| 67–70 min | Talk Robin 2 + Evidence | Submit time plan and risk controls. |

## Core Pattern

```text
0–30 read/audit → 30–90 baseline → 90–240 experiments → 240–330 final model/submission → 330–360 checks
```

## Required Evidence

1. Six-hour time budget.
2. Baseline-first plan.
3. Risk-control checklist.
