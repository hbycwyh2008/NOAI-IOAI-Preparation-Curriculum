# Lesson 06 — Round 1 CNN Short-Answer and Diagram Interpretation

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read a CNN diagram and one short-answer prompt. |
| 8–15 min | Talk Robin 1 | Discuss what the diagram shows. |
| 15–22 min | Entry Check | Identify convolution, pooling, and fully connected layers. |
| 22–35 min | Core Pattern | Teacher models diagram-to-explanation answers. |
| 35–53 min | Guided Practice | Interpret supported CNN diagrams and prompts. |
| 53–67 min | Independent Rebuild | Write one CNN explanation from a new diagram. |
| 67–70 min | Talk Robin 2 + Evidence | Submit explanation and self-check. |

## Core Pattern

```text
Diagram element → Layer role → Data transformation → Why it helps vision tasks
```

## Required Evidence

1. Layer identification table.
2. One diagram interpretation.
3. One Round 1 CNN short answer.
