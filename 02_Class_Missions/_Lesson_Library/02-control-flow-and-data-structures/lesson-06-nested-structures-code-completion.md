# Lesson 06 — Nested Structures and Round 1 Code-Completion Practice

**Duration:** 75 minutes

## Resource Delivery

**Pre-class required viewing:** Complete the assigned segments from **Harvard CS50’s Introduction to Programming with Python** before class. The classroom warm-up is an eight-minute retrieval task, not the full viewing period.

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Retrieve the nested-access pattern from pre-class viewing and inspect one nested list/dictionary example. |
| 8–15 min | Talk Robin 1 | Explain how to access an inner value. |
| 15–22 min | Entry Check | Complete two indexing/access questions. |
| 22–35 min | Core Pattern | Teacher models outer container → inner container → target field. |
| 35–53 min | Guided Practice | Complete missing lines in a nested-data program. |
| 53–67 min | Independent Rebuild | Create and query a nested structure. |
| 67–75 min | Talk Robin 2 + Evidence | Explain the code-completion choice and submit evidence. |

## 2. Talk Robin 1

Prompt: what is the outer container, what is the inner container, and which key/index reaches the target value?

## 3. Entry Check

Complete two indexing/access questions.

## 4. Core Pattern

```text
Outer item → choose key/index → inner item → choose field → update or read value
```

## 5. Guided Practice

Complete missing lines in a nested-data program.

## 6. Independent Rebuild

Create and query a nested structure.

## 7. Talk Robin 2 + Evidence

Submit timestamped resource notes, completed code, one nested-access trace, one rebuilt nested structure, and one distractor explanation.
