# Lesson 03 — Confusion-Matrix Consequences of Threshold Choice

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect predicted probabilities under two thresholds. |
| 8–15 min | Talk Robin 1 | Discuss why threshold changes errors. |
| 15–22 min | Entry Check | Count TP, FP, TN, and FN for a tiny table. |
| 22–35 min | Core Pattern | Teacher models probability → threshold → predicted class → confusion matrix. |
| 35–53 min | Guided Practice | Complete supported threshold trade-off table. |
| 53–67 min | Independent Rebuild | Choose a threshold for a new scenario. |
| 67–75 min | Talk Robin 2 + Evidence | Defend threshold choice. |

## Core Pattern

```text
Probability score → threshold → predicted label → error type → metric trade-off
```

## Evidence

Submit a threshold table, confusion-matrix counts, and one scenario-based threshold decision.
