# Lesson 05 — Metric Selection for Imbalanced and Real-World Tasks

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read an imbalanced classification scenario. |
| 8–15 min | Talk Robin 1 | Discuss why accuracy may be misleading. |
| 15–22 min | Entry Check | Identify the minority class and main risk. |
| 22–35 min | Core Pattern | Teacher explains task risk → metric choice → evidence. |
| 35–53 min | Guided Practice | Choose metrics for medical, spam, fraud, and image tasks. |
| 53–67 min | Independent Rebuild | Design a metric choice for a new NOAI-style scenario. |
| 67–70 min | Talk Robin 2 + Evidence | Submit metric decision and justification. |

## Learning Target

Students can choose evaluation metrics based on class imbalance, false-positive risk, false-negative risk, and competition scoring.

## Core Pattern

```text
Scenario risk → Class balance → Error cost → Metric choice → Justification
```

## Required Evidence

1. Scenario-risk table.
2. Metric choice for at least four tasks.
3. One written justification explaining why accuracy is insufficient.
