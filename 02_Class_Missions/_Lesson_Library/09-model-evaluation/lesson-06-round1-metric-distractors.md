# Lesson 06 — Round 1 Metric Calculation and Distractor Analysis

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Review one Round 1-style confusion-matrix item. |
| 8–15 min | Talk Robin 1 | Explain which wrong answer is most tempting. |
| 15–22 min | Entry Check | Calculate accuracy, precision, recall, and F1. |
| 22–35 min | Core Pattern | Teacher models distractor diagnosis. |
| 35–53 min | Guided Practice | Solve supported metric MCQs and short-answer items. |
| 53–67 min | Independent Rebuild | Write one original metric question with distractors. |
| 67–70 min | Talk Robin 2 + Evidence | Submit original question and explanation. |

## Learning Target

Students can solve paper-test metric questions and explain common distractors.

## Core Pattern

```text
Metric formula → Substitute values → Calculate → Check task meaning → Reject distractor
```

## Required Evidence

1. Completed metric calculations.
2. Distractor analysis.
3. One original Round 1-style metric question.
