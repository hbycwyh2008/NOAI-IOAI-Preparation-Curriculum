# 13 — Backpropagation and Optimisation

This module must give students enough time to understand training, gradients, backpropagation, optimiser choices, and common failure modes.

## Minimum Evidence

Students should be able to describe a full training step, explain what backpropagation computes, compare Adam/AdamW with plain gradient descent, and diagnose one optimisation failure.
