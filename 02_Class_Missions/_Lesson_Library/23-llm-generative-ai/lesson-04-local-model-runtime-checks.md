# Lesson 04 — Local/Offline Model Constraints, Quantisation, and Runtime Checks

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect runtime constraints and model-size options. |
| 8–15 min | Talk Robin 1 | Discuss memory, device, and offline risks. |
| 15–22 min | Entry Check | Identify model, device, precision, and dependency requirements. |
| 22–35 min | Core Pattern | Teacher models environment → model load → smoke test → failure record. |
| 35–53 min | Guided Practice | Complete supported runtime checklist. |
| 53–67 min | Independent Rebuild | Write a local/offline deployment risk memo. |
| 67–75 min | Talk Robin 2 + Evidence | Submit smoke-test plan. |

## Core Pattern

```text
Allowed environment → model/package choice → device/precision → smoke test → fallback plan
```

## Evidence

Submit runtime checklist, smoke-test record, and fallback plan.
