# Lesson 04 — Round 1 Ethics Case Reasoning and Short Answers

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read one AI ethics case. |
| 8–15 min | Talk Robin 1 | Identify stakeholders and risks. |
| 15–22 min | Entry Check | Classify privacy, bias, safety, and responsibility issues. |
| 22–35 min | Core Pattern | Teacher models claim → risk → evidence → mitigation. |
| 35–53 min | Guided Practice | Write a supported short answer. |
| 53–67 min | Independent Rebuild | Analyse a new case independently. |
| 67–75 min | Talk Robin 2 + Evidence | Explain and submit final answer. |

## Core Pattern

```text
Case → stakeholder → risk type → evidence → mitigation → responsible actor
```

## Evidence

Submit one case analysis, one short answer, and one misconception correction.
