## Video Delivery Rule

The timestamp tables are precise assignments, but many lesson packages exceed eight minutes. Therefore:

- the full listed package is normally completed **before class**;
- the in-class Skill Warm-Up lasts no more than eight minutes and uses one exact excerpt, retrieval check, or code trace;
- a teacher may schedule a separate video/resource session instead of pre-class viewing;
- a lesson must never claim that a 20–50 minute package fits inside an eight-minute warm-up.
