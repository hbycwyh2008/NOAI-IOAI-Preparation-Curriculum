# 14 — CNN Foundations

This module expands CNN learning beyond a short overview. Students need to explain layers, compute shapes, identify common errors, and connect CNNs to image/audio spectrogram tasks.

## Minimum Evidence

Students should submit one shape-calculation table, one layer-role explanation, one CNN error diagnosis, and one short-answer response suitable for Round 1.
