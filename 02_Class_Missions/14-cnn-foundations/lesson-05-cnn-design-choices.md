# Lesson 05 — CNN Design Choices: Channels, Depth, Augmentation, and Transfer

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare two CNN design sketches. |
| 8–15 min | Talk Robin 1 | Discuss which design is safer under limited data. |
| 15–22 min | Entry Check | Identify augmentation and transfer-learning choices. |
| 22–35 min | Core Pattern | Teacher explains design choice → constraint → evidence. |
| 35–53 min | Guided Practice | Choose CNN strategy for small/medium/large datasets. |
| 53–67 min | Independent Rebuild | Write a CNN design plan for a new image task. |
| 67–70 min | Talk Robin 2 + Evidence | Submit design memo. |

## Core Pattern

```text
Dataset size → Model capacity → Augmentation → Transfer learning → Validation evidence
```

## Required Evidence

1. CNN strategy comparison.
2. One augmentation policy.
3. One transfer-learning decision memo.
