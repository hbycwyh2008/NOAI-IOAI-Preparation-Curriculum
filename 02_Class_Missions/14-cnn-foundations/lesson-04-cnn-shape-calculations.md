# Lesson 04 — Convolution and Pooling Output-Size Calculations

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect convolution/pooling layer settings. |
| 8–15 min | Talk Robin 1 | Discuss where shape mistakes happen. |
| 15–22 min | Entry Check | Calculate one convolution output size. |
| 22–35 min | Core Pattern | Teacher explains input size, kernel, stride, padding, output size. |
| 35–53 min | Guided Practice | Complete supported CNN shape tables. |
| 53–67 min | Independent Rebuild | Design a tiny CNN and calculate layer shapes. |
| 67–70 min | Talk Robin 2 + Evidence | Submit shape ledger. |

## Core Pattern

```text
Input size + kernel + stride + padding → output size → next layer input
```

## Required Evidence

1. Convolution output-size calculation.
2. Pooling output-size calculation.
3. A complete CNN shape ledger.
