## Learning Target

By the end of this mission, you can explain the core ideas in **if/elif/else, Boolean logic, comparison, and boundary cases** and demonstrate them through a paper-based or computational task.

## 2. Talk Robin 1

Each student explains which branch executes for a given input. Partners identify missing boundary cases.

## 3. Entry Check

1. Trace one `if/elif/else` chain.
2. Explain why two independent `if` statements differ from `if` followed by `elif`.
3. Write one valid probability boundary condition.

## 4. Core Pattern

```text
Input/state → condition check → first true branch → branch effect → final output/state
```

## 5. Guided Practice

Solve code-tracing and branch-boundary questions.

## 6. Independent Rebuild

Write a decision function from a fresh prompt.

## 7. Talk Robin 2 + Evidence

Submit CS50P segment notes, one boundary table, one branch trace, and one rebuilt decision function.
