# Lesson 04 — String and List Transformation Patterns

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect transformations on strings and lists. |
| 8–15 min | Talk Robin 1 | Explain what changes and what stays unchanged. |
| 15–22 min | Entry Check | Predict output for slicing, appending, and filtering. |
| 22–35 min | Core Pattern | Teacher models scan → test → transform → collect. |
| 35–53 min | Guided Practice | Complete supported transformation tasks. |
| 53–67 min | Independent Rebuild | Rebuild one transformation from scratch. |
| 67–75 min | Talk Robin 2 + Evidence | Submit trace and explanation. |

## Core Pattern

```text
Input sequence → visit each item → apply condition → transform item → collect result
```

## Evidence

Submit a trace table, one string transformation, one list transformation, and one explanation of mutation versus new-list construction.
