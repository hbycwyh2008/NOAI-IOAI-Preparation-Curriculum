# Lesson 06 — Nested Structures and Round 1 Code-Completion Practice

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect nested lists and dictionaries. |
| 8–15 min | Talk Robin 1 | Explain how to access an inner value. |
| 15–22 min | Entry Check | Complete two indexing/access questions. |
| 22–35 min | Core Pattern | Teacher models outer container → inner container → target field. |
| 35–53 min | Guided Practice | Complete missing lines in a nested-data program. |
| 53–67 min | Independent Rebuild | Create and query a nested structure. |
| 67–75 min | Talk Robin 2 + Evidence | Explain code-completion choice. |

## Core Pattern

```text
Outer item → choose key/index → inner item → choose field → update or read value
```

## Evidence

Submit completed code, one nested-access trace, one rebuilt nested structure, and one distractor explanation.
