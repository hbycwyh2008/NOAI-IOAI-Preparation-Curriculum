# Lesson 06 — Feature Experiment Report and Ablation Table

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read a before/after feature experiment table. |
| 8–15 min | Talk Robin 1 | Discuss whether the feature really helped. |
| 15–22 min | Entry Check | Identify baseline, feature group, metric, and change. |
| 22–35 min | Core Pattern | Teacher models baseline → add feature → validate → ablate → decide. |
| 35–53 min | Guided Practice | Complete supported ablation report. |
| 53–67 min | Independent Rebuild | Design one feature experiment. |
| 67–75 min | Talk Robin 2 + Evidence | Submit report and decision. |

## Core Pattern

```text
Baseline → feature hypothesis → controlled experiment → ablation → metric change → keep/drop decision
```

## Evidence

Submit an ablation table, one feature hypothesis, and one decision memo.
