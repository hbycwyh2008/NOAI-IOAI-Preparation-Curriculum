# Lesson 03 — Prompt Design, Structured Output, and Verification Records

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Compare vague and structured prompts. |
| 8–15 min | Talk Robin 1 | Discuss what must be verified by the student. |
| 15–22 min | Entry Check | Identify task, constraint, format, and verification test. |
| 22–35 min | Core Pattern | Teacher models prompt → output schema → validation → revision. |
| 35–53 min | Guided Practice | Complete supported structured-output prompt. |
| 53–67 min | Independent Rebuild | Design a prompt and verification record for a new task. |
| 67–75 min | Talk Robin 2 + Evidence | Submit prompt log and verification. |

## Core Pattern

```text
Task → constraints → output schema → model response → verification test → revision record
```

## Evidence

Submit prompt log, structured output, verification test, and revision note.
