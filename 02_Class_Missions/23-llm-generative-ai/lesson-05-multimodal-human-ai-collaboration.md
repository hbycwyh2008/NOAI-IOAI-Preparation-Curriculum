# Lesson 05 — Multimodal Task Reading and Human-AI Collaboration Evidence

**Duration:** 75 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Inspect a multimodal task with text and image/audio/table input. |
| 8–15 min | Talk Robin 1 | Discuss what the model can help with and what the student must verify. |
| 15–22 min | Entry Check | Separate task understanding, model output, and verification. |
| 22–35 min | Core Pattern | Teacher models task → modalities → AI assistance → human decision → evidence. |
| 35–53 min | Guided Practice | Complete supported collaboration record. |
| 53–67 min | Independent Rebuild | Create a collaboration plan for a new task. |
| 67–75 min | Talk Robin 2 + Evidence | Submit human-AI evidence. |

## Core Pattern

```text
Task → modality inventory → AI-assisted step → human verification → final decision → evidence log
```

## Evidence

Submit modality inventory, prompt log, verification record, and student-decision note.
