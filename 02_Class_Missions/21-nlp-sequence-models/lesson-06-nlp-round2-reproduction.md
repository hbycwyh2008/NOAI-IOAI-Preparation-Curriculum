# Lesson 06 — NLP Round 2 Reproduction: Baseline, Model, Metric, Submission

**Duration:** 70 minutes

## Timeline

| Time | Block | Student output |
|---|---|---|
| 0–8 min | Skill Warm-Up | Read an NLP Round 2-style task brief. |
| 8–15 min | Talk Robin 1 | Discuss the baseline and metric. |
| 15–22 min | Entry Check | Identify input, output, split, and score. |
| 22–35 min | Core Pattern | Teacher explains NLP task → baseline → sequence model → validation → submission. |
| 35–53 min | Guided Practice | Build a reproduction plan. |
| 53–67 min | Independent Rebuild | Write a new reproduction plan for a similar task. |
| 67–70 min | Talk Robin 2 + Evidence | Submit task plan and validation memo. |

## Core Pattern

```text
Task brief → Data audit → Baseline → Model candidate → Metric → Submission format → Error analysis
```

## Required Evidence

1. NLP task decomposition.
2. Baseline/model comparison plan.
3. Validation and submission memo.
