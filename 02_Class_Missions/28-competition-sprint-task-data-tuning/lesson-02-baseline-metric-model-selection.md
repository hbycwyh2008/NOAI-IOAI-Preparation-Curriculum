# Legacy Path — Model Selection Is Now Lesson 04

This file is retained so older links do not break.

The competition sprint now follows the evidence-based order:

```text
Task definition
→ data quality and validation
→ feature engineering
→ model selection and baseline
→ tuning
→ model ensembling
```

Use the canonical lesson:

[Lesson 04 — Model Selection, Baseline Ladder, and Error Analysis](lesson-04-model-selection-baseline.md)

Model selection was moved after data quality and feature engineering because model comparisons are not trustworthy until the split, leakage checks, and feature pipeline are fixed.
