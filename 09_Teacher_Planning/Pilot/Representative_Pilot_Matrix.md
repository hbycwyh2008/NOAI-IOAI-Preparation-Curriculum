# Representative Pilot Matrix

This matrix turns the phrase “pilot the curriculum” into a minimum inspectable evidence set. A public repository can provide the protocol and blank records; only a real cohort can complete the evidence.

## Required Representative Pilots

| Lesson type | Minimum representative session | Evidence required | Pass condition |
|---|---|---|---|
| Orientation and evidence | Session 2 or equivalent | setup success, Git workflow, evidence submission | at least 80% complete the workflow without teacher file repair |
| CS50P Python | one functions/control lesson and one file/test lesson | entry accuracy, debugging independence, submission time | at least 70% complete guided work and 50% complete independent rebuild |
| NumPy/Pandas/visualisation | one data-audit lesson | schema errors, vectorisation issues, plot interpretation | median timing within declared duration and no unresolved environment blocker |
| Bohrium video foundation | one early and one late 70-minute lesson | access, viewing minutes, retrieval, independent evidence | video access works and the evidence cycle fits the named exception |
| AI History reading seminar | one of Sessions 33–40 | reading completion, claim/evidence distinction, independent reconstruction | at least 70% pass entry check and 50% produce an evidence-bounded rebuild |
| Andrew Ng ML model lab | one regression/classification and one tree/unsupervised lesson | task recognition, maths intuition, baseline, error analysis | students identify `X`, `y`, task, baseline, metric, and limitation before modelling |
| Andrew Ng DL + PyTorch | one complete training-loop lesson | fresh-kernel execution, tensor-shape errors, baseline comparison | maintained notebook and student rebuild both run in the target environment |
| Domain task | one CV, NLP, audio, or multimodal lesson | data pipeline, error slices, compute limits | student evidence includes a valid baseline and domain-specific error analysis |
| Evaluation and tuning | one validation lesson and one tuning lesson | leakage checks, experiment log, decision rationale | no test-set tuning and every experiment has a stated hypothesis |
| Competition simulation | Session 77 or equivalent | fresh start, submission validation, runtime, postmortem | valid submission produced within the target duration with reproducible evidence |

## Revision Triggers

Revise the lesson when:

- more than 25% cannot start because a prerequisite is missing;
- fewer than 70% complete the guided task;
- fewer than 50% complete the independent rebuild;
- median timing exceeds the declared duration by more than 10 minutes;
- setup consumes more than 10% of lesson time;
- a shared misconception remains after the exit check;
- students can run or quote material but cannot explain the mechanism or claim boundary.

## Completion Rule

Representative-pilot coverage is complete only when every row has a dated record linked to the exact curriculum commit. Full-pathway readiness remains separate and requires a real cohort to complete the selected route.
