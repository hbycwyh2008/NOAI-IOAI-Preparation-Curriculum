# Canonical Phase 7 — Model Comparison, EDA, and Evaluation

**Sessions:** 71–74  
**Canonical folder:** `02_Class_Missions/07_Model_Comparison_EDA_Evaluation/`

## Purpose

Systematise model differences, data quality, feature engineering, validation design, metrics, thresholds, calibration, and error analysis after students have experienced multiple model families.

## Entry Conditions

Students have completed representative classical and deep-learning tasks and can produce reproducible training and validation evidence.

## Delivery Priorities

- assumptions, strengths, limitations, interpretability, data demand, training cost, and inference cost across model families;
- schema, identifiers, missingness, duplicates, outliers, imbalance, groups/time, distribution shift, and leakage;
- reproducible encoding, scaling, domain features, feature selection, and ablation;
- train/validation/test design, cross-validation, metrics, thresholds, calibration, learning curves, slices, and failure cases;
- decision-making from evidence rather than preference or leaderboard score.

## Required Evidence

- model-family comparison matrix;
- question-driven EDA report;
- leakage-safe feature pipeline;
- ablation record;
- defended validation protocol and metric choice;
- error taxonomy with next-action priorities.

## Exit Gate

The student can inspect an unfamiliar dataset, identify leakage and split risks, choose a defensible model family and metric, evaluate uncertainty and failure slices, and explain what evidence is still missing.
