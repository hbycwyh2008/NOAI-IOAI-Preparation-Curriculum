# Canonical Phase 0 — Orientation and Evidence

**Sessions:** 1–2  
**Canonical folder:** `02_Class_Missions/00_Orientation_and_Evidence/`

## Purpose

Establish the course workflow, permitted assistance, evidence standards, repository habits, and competition context before technical instruction begins.

## Entry Conditions

No machine-learning knowledge is required. Students need account access, a working browser, and willingness to document their own decisions and errors.

## Delivery Priorities

- explain the 78-session dependency path;
- distinguish lesson completion from mastery evidence;
- set up the student repository and meaningful commit workflow;
- teach the AI-assistance record and verification requirement;
- establish public/private assessment boundaries;
- verify that every student can open, edit, run, save, and submit the required artifacts.

## Required Evidence

- successful environment and repository check;
- first meaningful commit;
- completed evidence example;
- student explanation of permitted and prohibited assistance;
- documented escalation route for access or runtime failure.

## Exit Gate

The student can independently find the assigned phase, use the lesson cycle, submit evidence, record AI assistance, and recover from a basic repository or notebook mistake.
