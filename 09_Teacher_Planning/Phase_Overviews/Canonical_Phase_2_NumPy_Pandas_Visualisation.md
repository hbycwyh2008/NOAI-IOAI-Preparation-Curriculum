# Canonical Phase 2 — NumPy, Pandas, and Visualisation

**Sessions:** 13–18  
**Canonical folder:** `02_Class_Missions/02_NumPy_Pandas_Visualisation/`

## Purpose

Move students from general Python programs to reliable data inspection, transformation, summary, and visual reasoning.

## Entry Conditions

Students pass the CS50P phase gate and can independently write functions, loops, file-processing code, and basic tests.

## Delivery Priorities

- NumPy arrays, shapes, dtypes, indexing, vectorisation, and broadcasting;
- Pandas schemas, selection, filtering, grouping, merging, reshaping, and summary statistics;
- missing values, duplicates, type errors, identifiers, and suspicious columns;
- Matplotlib plots chosen from a question rather than decoration;
- explicit links between rows/samples, columns/features, and later `X`/`y` modelling notation.

## Required Evidence

- shape and dtype explanations;
- vectorised replacement for a correct loop;
- reproducible DataFrame transformation;
- data-quality report;
- at least three question-driven plots with written interpretations;
- mini EDA project executed from a fresh kernel.

## Exit Gate

The student can load an unfamiliar CSV, inspect its schema, identify quality risks, transform data reproducibly, produce defensible plots, and explain what each row and column means before modelling.
