# Canonical Phase 1 — CS50P Python

**Sessions:** 3–12  
**Canonical folder:** `02_Class_Missions/01_CS50P_Python/`

## Purpose

Build enough independent Python fluency that later data and machine-learning lessons are not reduced to copying notebook cells.

## Entry Conditions

Students can use the course evidence workflow and access the assigned CS50P materials.

## Delivery Priorities

- functions, variables, input, output, and types;
- conditionals, loops, strings, lists, dictionaries, and tuples;
- decomposition, tracing, modules, imports, and documentation;
- exceptions and defensive input handling;
- files, CSV records, tests, classes, and debugging evidence;
- data-oriented transfer tasks after each programming concept.

## Required Evidence

- code written from a blank file;
- trace or prediction before execution;
- at least one failing case and documented fix;
- unit tests or assertions;
- CSV/file-processing artifact;
- independent mini-project with a meaningful commit history.

## Exit Gate

The student can read, write, test, and debug a small Python program without depending on a supplied notebook, and can explain control flow, data structures, functions, file handling, and errors.
