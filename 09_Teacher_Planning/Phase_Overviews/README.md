# Teacher Phase Overviews

These files are concise teacher-facing phase summaries. They identify purpose, entry gates, exit standards, and links to canonical lessons.

They do **not** contain a second copy of complete lesson bodies.

## Source-of-Truth Priority

1. `02_Class_Missions/` — lesson content, evidence, and lesson-specific duration;
2. `00_Course_Overview/Detailed_Lesson_Sequence.md` — scheduled Sessions 1–75;
3. `00_Course_Overview/Pacing_Guide.md` — timing and pathway policy;
4. `10_Ready_to_Teach_Pack/Phase_*.md` — scheduled phase indexes and assessment packs;
5. this folder — concise planning summaries only.

When a phase overview conflicts with a Class Mission, correct the overview and use the Class Mission.
