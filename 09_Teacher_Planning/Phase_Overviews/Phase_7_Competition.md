Sessions 58–67.

## Purpose

Students integrate task reading, data audit, leakage-safe validation, baseline-first development, controlled experiments, official-style reproduction, timed mocks, submission reliability, and readiness decisions.

## Entry Gate

Students should already be able to:

1. identify target, metric, unit of prediction, and submission schema;
2. create a defensible validation split;
3. build a simple valid baseline;
4. generate a valid submission from a fresh runtime;
5. explain one controlled experiment.

## Exit Standard

Students must show:

- a defensible data/validation memo;
- a reproducible baseline in at least two task modalities;
- controlled experiment and error-analysis records;
- valid long-mock submissions;
- sufficient Round 1 reliability;
- an evidence-based readiness status.

Students move to Phase 8 only after they can already build and defend a valid baseline.
