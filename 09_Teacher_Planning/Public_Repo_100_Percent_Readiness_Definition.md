# Public Repo 100 Percent Readiness Definition

This file defines what **100% readiness** means for the public student-facing NOAI / IOAI preparation repository.

It does not mean that hidden teacher keys, private labels, and complete solutions are public. Those must remain outside this repo.

## Public Repo Is 100% Ready When

1. Every main module has a realistic lesson sequence.
2. Every listed lesson has a corresponding student-facing lesson file.
3. Every ordinary lesson uses the classroom flow:

   **Skill Warm-Up → Talk Robin 1 → Entry Check → Core Pattern → Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence**

4. Every lesson states required evidence.
5. Full-video Bohrium lessons have complete multi-session handling.
6. BML15 is split into 14 teachable 70-minute lessons.
7. Round 1 paper-test preparation has enough code-reading, calculation, distractor, and short-answer practice.
8. Round 2 project preparation has enough notebook, validation, baseline, ablation, submission, and postmortem structure.
9. Worksheet templates exist for ordinary lessons and Round 1 paper practice.
10. Notebook templates and coverage expectations exist for Round 2 coding-heavy lessons.
11. Teacher-key private repo boundaries are explicit.
12. Validation and pilot checklists exist.

## What Remains Outside the Public Repo

These are required for live teaching, but they must be private:

- answer keys;
- full solutions;
- hidden labels;
- private test sets;
- exact scored assessment rubrics;
- teacher calibration examples.

## Status

When `Lesson_Distribution_Audit.md` reports 100% public structural readiness, the public repo is ready for curriculum delivery planning and student-facing use.

Before high-stakes graded use, the teacher must complete the private teacher-key repository and run runtime/link/notebook validation.
