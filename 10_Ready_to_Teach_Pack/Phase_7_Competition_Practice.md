# Extended Competition Practice — Reusable Teacher Index

This file predates the canonical 78-session pathway. It is retained as a teacher-facing index for long reproductions, timed mocks, and readiness conferences drawn from `_Lesson_Library`.

It is **not canonical Phase 7**, does not define session numbers, and must not replace Sessions 71–74 in `02_Class_Missions/07_Model_Comparison_EDA_Evaluation/`.

## Canonical Placement

- Canonical Phase 7: Sessions 71–74 — model comparison, EDA, feature engineering, evaluation, and error analysis.
- Canonical Phase 8: Sessions 75–78 — tuning, ensembling, full simulation, and postmortem.
- The activities below are selected before, during, or after these phases when a cohort needs longer competition practice.

## Source Rule

- `02_Class_Missions/README.md` is the source of truth for phase order and session ranges.
- `00_Course_Overview/Detailed_Lesson_Sequence.md` is the source of truth for Sessions 1–78.
- `_Lesson_Library` is the source of truth for the reusable lesson bodies listed below.
- This file provides selection guidance only.

## Selection Gate

Assign a long practice only when the student can already:

1. identify task type, target, official metric, and submission schema;
2. create a leakage-safe train/validation split;
3. build a simple valid baseline before advanced modelling;
4. generate a valid submission from a fresh runtime;
5. record one controlled experiment and explain the decision;
6. use documentation and AI assistance without submitting work they cannot explain.

## Teacher Verification

Before each reproduction or mock, confirm:

- current official rules and permitted tools;
- dataset and task licensing;
- whether internet, APIs, pretrained models, and external data are allowed;
- runtime, memory, storage, and submission limits;
- which answers, hidden labels, calibration examples, and scoring materials remain private;
- exact student runtime qualification.

## Evidence Rule

Completion of one activity does not create a new canonical session or prove full competition readiness. Record it as additional evidence in the representative pilot matrix, student readiness record, and postmortem system.
