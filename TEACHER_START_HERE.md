# Teacher Start Here

## Use One Teaching Order

Begin at [Class Missions — Canonical Learning Pathway](02_Class_Missions/README.md). The phase folders define the scheduled route; `_Lesson_Library` is a bank for selection and remediation, not an alternative sequence.

## Required Order

1. Orientation and evidence
2. CS50P Python
3. NumPy, Pandas, and Matplotlib
4. 北京市十一学校《中学机器学习十五讲》 on Bohrium
5. AI history and critical reading through Melanie Mitchell’s *Artificial Intelligence: A Guide for Thinking Humans*
6. Andrew Ng Machine Learning Specialization with StatQuest, 3Blue1Brown, embedded Kaggle practice, model recognition, and typical tasks
7. Andrew Ng Deep Learning Specialization paired with PyTorch and domain tasks
8. Model comparison, EDA, data quality, feature engineering, evaluation, and error analysis
9. Diagnosis-first tuning, model ensembling, competition simulation, and postmortem

## Planning Steps

1. Archive current official NOAI/IOAI rules and permitted-tool information.
2. Run the student diagnostic.
3. Use the [Detailed 78-Session Sequence](00_Course_Overview/Detailed_Lesson_Sequence.md).
4. Ensure that students have legal access to the Melanie Mitchell book before Sessions 33–40.
5. Select remediation or extension only from the linked lesson-library modules.
6. Verify exact video segments and authenticated resources.
7. Run notebooks and starter code in the student environment.
8. Collect one evidence package per mission.
9. Keep solutions, hidden labels, private tests, and calibration material in the private teacher-key repository.

## Reading-Seminar Rule

Sessions 33–40 assume that the assigned pages are read before class. Do not replace the learning cycle with seventy minutes of silent reading. The seminar must preserve retrieval, discussion, entry checking, claim analysis, guided practice, independent reconstruction, and evidence.

## Resource Boundaries

- CS50P is the Python spine.
- Bohrium foundations are completed before the AI-history phase.
- Melanie Mitchell’s book supplies historical context, conceptual boundaries, and evidence-based judgement.
- Kaggle is embedded practice within Andrew Ng ML, not a separate theory phase.
- Andrew Ng ML is paired with just-in-time StatQuest and 3Blue1Brown intuition.
- Model recognition and typical tasks are continuous.
- Andrew Ng DL concepts are paired immediately with PyTorch implementations.
- EDA and evaluation are introduced inside tasks, then systematised after the model curriculum.
- Tuning follows diagnosis; ensembling follows stable single models.

## Core Delivery Rule

Every ordinary lesson follows:

**Skill Warm-Up → Talk Robin 1 → Entry Check → Core Pattern → Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence**

Do not schedule all 171 lesson/resource files.
